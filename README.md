# Фронтенд с нуля

Курс фронтенд-разработки для взрослых новичков: от «что такое сервер» до своего фулстек-приложения. Под macOS, на русском. Уроки, слайды, сценарии для ментора, квизы и задания с проверкой в браузере.

**Сайт курса:** https://leofunow.github.io/Frontend-Courses/

## Как смотреть локально

```bash
npm install
npm start          # http://localhost:3000, страницы обновляются сами при правках
```

Готовый сайт лежит в `docs/` и открывается и без сервера — двойным щелчком по `docs/index.html`.

## Как устроено

```text
src/syllabus.yml        программа курса
src/lessons/NN-id/      урок: lesson.md, slides.md, script.md, img/, screenshots.yml
src/glossary.yml        глоссарий
build/                  сборка и проверки
assets/                 стили и скрипты сайта
docs/                   собранный сайт — его раздаёт GitHub Pages
STYLE.md                как писать уроки
```

## Проверки

```bash
npm run check          # сборка, объём и стиль текстов, ссылки, вёрстка, домашки, тесты интерфейса
```
