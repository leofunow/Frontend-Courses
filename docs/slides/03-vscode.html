Воркшоп: мини-проект в VS Code — 18 мин

На слайде: шесть шагов мини-проекта.

Подготовить заранее: закройте все окна VS Code. Увеличьте масштаб для экрана: ⌘+= два раза. Держите открытой папку ~/dev/homework — понадобится на шаге 6.

Показать вживую:

  1. Открыть папку. Меню File → Open Folder (⌘+O) → dev → кнопка New Folder внизу окна → workshop-vscode → Open.
    • На вопрос «Do you trust the authors» → Yes, I trust the authors.
    • Покажите четыре зоны: панель действий слева, проводник, редактор, строка состояния.
  2. Файлы. Наведите мышь на название папки в проводнике — справа появятся иконки.
    • Иконка New File → index.html → Enter.
    • Иконка New Folder → css. Правый щелчок по css → New File → style.css.
  3. Emmet. В index.html наберите ! → Tab — готов каркас. Поменяйте lang="en" на lang="ru": двойной щелчок по en, напечатать ru.
    • Внутри body: header>nav>a*3 → Tab.
    • Ниже: main>h1{Кофейня}+ul>li.dish*4 → Tab.
  4. Горячие клавиши.
    • Выделите мышью href="" у первой ссылки → ⌘+D ещё дважды — выделены все три. Напечатайте href="#" — поменялись все ссылки сразу. Esc — снова один курсор.
    • Курсор на строке <h1> → ⌥+↑ — строка поднялась. ⇧+⌥+↓ — копия строки ниже.
    • ⌘+/ — закомментировать строку, ещё раз — вернуть.
    • ⌘+P → наберите sty → Enter: открылся style.css без мыши.
  5. Biome. Вернитесь в index.html и добавьте <img src="logo.png">.
    • Появится волнистая линия. Наведите — сообщение про alt.
    • ⇧+⌘+M — панель Problems со всеми ошибками. Щелчок по строке переносит к ошибке.
    • Допишите alt="Логотип" — ошибка пропала.
    • Сломайте отступы и нажмите ⌘+S — Biome выровнял код при сохранении.
  6. Live Server. Справа внизу в строке состояния — Go Live. Щелчок → Chrome откроет http://127.0.0.1:5500.
    • Поставьте окна рядом, поменяйте текст h1 → ⌘+S — страница обновилась сама.
  7. Терминал внутри. ⌃+</kbd> — снизу открылся терминал уже в папке проекта. ls` — видны наши файлы.
    • File → Open Recent → homework. В терминале npx biome check 03-vscode — так ученик проверяет домашку.
  8. Настройки. ⌘+, → в поиске font size → поменяйте на 16. Иконка с листком справа вверху — те же настройки в settings.json.

Рассказать: за 15 минут — страница без единого щелчка по меню. Ученику не нужно запоминать всё сразу: достаточно Emmet, ⌘+P, ⌘+D и Go Live.
