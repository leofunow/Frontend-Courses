display

Значение Что делает
block новая строка, вся ширина
inline в строку с текстом
none исчезает
flex дети в ряд
grid дети в сетку

Flexbox: шапка — 6 мин

На слайде: три строки CSS для шапки.

Показать вживую: песочница «Шапка на Flexbox»: убрать display flex, убрать justify-content, поменять space-between на center.

Промежутки и размеры

Свойство Что делает
gap: 16px промежутки между элементами
flex-wrap: wrap перенос на новую строку
flex: 1 занять свободное место
margin-left: auto отодвинуть вправо

Промежутки и размеры — 7 мин

На слайде: gap, wrap, flex: 1, margin-left: auto.

Показать вживую: песочница «Поиск на всю ширину». Затем в шапке ученика отодвинуть кнопку вправо через margin-left: auto.

Flexbox или Grid — 4 мин

На слайде: таблица задач.

Частые ошибки

  • display: flex не у того элемента
  • Путают justify и align
  • Промежутки через margin вместо gap
