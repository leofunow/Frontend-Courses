## Воркшоп: мини-проект в VS Code (18 мин)

**На слайде:** шесть шагов мини-проекта.

**Подготовить заранее:** закройте все окна VS Code. Увеличьте масштаб для экрана: <kbd>⌘</kbd>+<kbd>=</kbd> два раза. Держите открытой папку `~/dev/homework` — понадобится на шаге 6.

**Показать вживую:**
1. **Открыть папку.** Меню File → Open Folder (<kbd>⌘</kbd>+<kbd>O</kbd>) → `dev` → кнопка New Folder внизу окна → `workshop-vscode` → Open.
   - На вопрос «Do you trust the authors» → Yes, I trust the authors.
   - Покажите четыре зоны: панель действий слева, проводник, редактор, строка состояния.
2. **Файлы.** Наведите мышь на название папки в проводнике — справа появятся иконки.
   - Иконка New File → `index.html` → Enter.
   - Иконка New Folder → `css`. Правый щелчок по `css` → New File → `style.css`.
3. **Emmet.** В `index.html` наберите `!` → <kbd>Tab</kbd> — готов каркас. Поменяйте `lang="en"` на `lang="ru"`: двойной щелчок по `en`, напечатать `ru`.
   - Внутри `body`: `header>nav>a*3` → <kbd>Tab</kbd>.
   - Ниже: `main>h1{Кофейня}+ul>li.dish*4` → <kbd>Tab</kbd>.
4. **Горячие клавиши.**
   - Выделите мышью `href=""` у первой ссылки → <kbd>⌘</kbd>+<kbd>D</kbd> ещё дважды — выделены все три. Напечатайте `href="#"` — поменялись все ссылки сразу. <kbd>Esc</kbd> — снова один курсор.
   - Курсор на строке `<h1>` → <kbd>⌥</kbd>+<kbd>↑</kbd> — строка поднялась. <kbd>⇧</kbd>+<kbd>⌥</kbd>+<kbd>↓</kbd> — копия строки ниже.
   - <kbd>⌘</kbd>+<kbd>/</kbd> — закомментировать строку, ещё раз — вернуть.
   - <kbd>⌘</kbd>+<kbd>P</kbd> → наберите `sty` → Enter: открылся `style.css` без мыши.
5. **Biome.** Вернитесь в `index.html` и добавьте `<img src="logo.png">`.
   - Появится волнистая линия. Наведите — сообщение про `alt`.
   - <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>M</kbd> — панель Problems со всеми ошибками. Щелчок по строке переносит к ошибке.
   - Допишите `alt="Логотип"` — ошибка пропала.
   - Сломайте отступы и нажмите <kbd>⌘</kbd>+<kbd>S</kbd> — Biome выровнял код при сохранении.
6. **Live Server.** Справа внизу в строке состояния — Go Live. Щелчок → Chrome откроет `http://127.0.0.1:5500`.
   - Поставьте окна рядом, поменяйте текст `h1` → <kbd>⌘</kbd>+<kbd>S</kbd> — страница обновилась сама.
7. **Терминал внутри.** <kbd>⌃</kbd>+<kbd>`</kbd> — снизу открылся терминал уже в папке проекта. `ls` — видны наши файлы.
   - File → Open Recent → `homework`. В терминале `npx biome check 03-vscode` — так ученик проверяет домашку.
8. **Настройки.** <kbd>⌘</kbd>+<kbd>,</kbd> → в поиске `font size` → поменяйте на 16. Иконка с листком справа вверху — те же настройки в `settings.json`.

**Рассказать:** за 15 минут — страница без единого щелчка по меню. Ученику не нужно запоминать всё сразу: достаточно Emmet, <kbd>⌘</kbd>+<kbd>P</kbd>, <kbd>⌘</kbd>+<kbd>D</kbd> и Go Live.
