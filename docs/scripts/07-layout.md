Что открыть заранее: слайды, текст урока (песочницы), VS Code с домашкой, Chrome. Откройте Flexbox Froggy на русском — пригодится в конце, если останется время.

Цель занятия: ученик ставит элементы в ряд и по центру через Flexbox, раскладывает карточки и страницу через Grid и объясняет, когда что брать.

## Титульный слайд (1 мин)

**На слайде:** название урока.

**Рассказать:** до сегодня всё стояло столбиком. Сегодня научимся ставить элементы куда нужно.

## Две раскладки на все случаи (1 мин)

**На слайде:** тезис.

**Рассказать:** старые способы — float, таблицы — забываем. Flexbox и Grid покрывают всё.

## Поток документа (4 мин)

**На слайде:** блочные и строчные элементы.

**Рассказать:** почему заголовок всегда с новой строки, а ссылка — нет.

## display (3 мин)

**На слайде:** таблица значений display.

**Показать вживую:** в DevTools поменять `display` у абзаца на `inline` и `none`.

## Flexbox: шапка (6 мин)

**На слайде:** три строки CSS для шапки.

**Показать вживую:** песочница «Шапка на Flexbox»: убрать display flex, убрать justify-content, поменять space-between на center.

**Спросить:** «Кому пишем display: flex — header или ссылкам?» Ответ: header — родителю.

## Две оси (4 мин)

**На слайде:** главная и поперечная оси.

**Рассказать:** justify — вдоль, align — поперёк. После flex-direction column роли меняются.

## justify-content (5 мин)

**На слайде:** шесть значений.

**Рассказать:** запоминать все не нужно: чаще всего хватает space-between и center.

**Спросить:** ученик называет, какое значение нужно для шапки и для кнопок «Назад / Далее» по краям.

## align-items (4 мин)

**На слайде:** четыре значения на элементах разной высоты.

**Рассказать:** stretch — по умолчанию, поэтому колонки одинаковой высоты «сами».

## Точно по центру (4 мин)

**На слайде:** центрирование в три строки.

**Показать вживую:** песочница «Точно по центру». Поменять высоту — блок остаётся в центре.

## Промежутки и размеры (7 мин)

**На слайде:** gap, wrap, flex: 1, margin-left: auto.

**Показать вживую:** песочница «Поиск на всю ширину». Затем в шапке ученика отодвинуть кнопку вправо через margin-left: auto.

## Grid: колонки (7 мин)

**На слайде:** сетка из трёх колонок по 1fr.

**Показать вживую:** песочница «Каталог на Grid»: 3 → 2 колонки, 1fr → 200px.

**Спросить:** «Колонок три, карточек семь. Где окажется седьмая?» Ответ: одна в третьей строке, в первой колонке.

## Адаптивная сетка (5 мин)

**На слайде:** auto-fill и minmax.

**Показать вживую:** в песочнице заменить колонки на auto-fill и сузить окно браузера — колонки перестраиваются.

## Макет страницы (7 мин)

**На слайде:** grid-template-areas.

**Показать вживую:** песочница «Макет из областей»: поменять aside и main местами в схеме.

## Flexbox или Grid (4 мин)

**На слайде:** таблица задач.

**Рассказать:** одна линия — Flexbox, строки и колонки — Grid. Их можно вкладывать друг в друга.

**Спросить:** ученик по трём картинкам любых сайтов называет, где Flexbox, где Grid.

## Частые ошибки (2 мин)

**На слайде:** три ошибки.

**Показать вживую:** значок flex или grid в DevTools → Elements: сетка подсвечивается на странице.

## Домашнее задание (3 мин)

**На слайде:** четыре задания.

**Рассказать:** проверки на странице меряют расположение элементов, а не только свойства. Можно решить разными способами.
