Что открыть заранее: слайды, текст урока (песочницы), VS Code с домашкой, Chrome. Откройте Flexbox Froggy на русском — пригодится в конце, если останется время.

Цель занятия: ученик ставит элементы в ряд и по центру через Flexbox, раскладывает карточки и страницу через Grid, кладёт значок поверх карточки через position и добавляет плавность при наведении.

**На слайде:** таблица static, relative, absolute, fixed, sticky.

**Рассказать:** запомнить главное: relative — точка отсчёта, absolute — поверх, sticky — прилипает при прокрутке.

## relative, absolute, z-index (4 мин)

**На слайде:** сдвиг relative, значок в углу, три наложенных блока.

**Рассказать:** relative двигает элемент, но место под ним остаётся. z-index — кто ближе к нам, работает только у позиционированных элементов.

## transform (3 мин)

**На слайде:** сдвиг, поворот, масштаб и приподнятая карточка.

**Рассказать:** transform не двигает соседей, поэтому для анимаций берут его, а не margin или top.

**На слайде:** transition и :hover у карточки.

**Показать вживую:** песочница «Карточка приподнимается»: убрать transition — подъём стал резким. Поменять 0.2s на 2s — слишком медленно.

## @keyframes (3 мин)

**На слайде:** анимация pulse.

**Рассказать:** keyframes — кадры, между которыми браузер рисует движение. infinite — повторять, alternate — туда и обратно.

## Анимация — в меру (2 мин)

**На слайде:** тезис и prefers-reduced-motion.

**Рассказать:** у некоторых людей от движения на экране кружится голова. Системная настройка «Уменьшить движение» — в Настройки → Универсальный доступ → Дисплей. Её уважаем через prefers-reduced-motion.

## Воркшоп: шапка, каталог и макет (15 мин)

**На слайде:** четыре шага: шапка, каталог, макет, то, что поверх.

**Подготовить заранее:** `workshop-html` с прошлых уроков, Go Live, DevTools закреплён снизу (⋮ → Dock side → вторая иконка) — так раскладку лучше видно. Создайте `catalog.html` с каркасом и `css/catalog.css`.

**Показать вживую:**
1. **Шапка.** В `catalog.html`: `header.header>strong{Зерно}+nav.nav>a*3` → <kbd>Tab</kbd>.
   - В CSS: `.header { display: flex; }` — логотип и меню встали в ряд.
   - DevTools → Elements: рядом с `<header>` значок `flex`. Щёлкните — на странице пунктир вокруг элементов ряда.
2. **Редактор Flexbox.** В панели Styles рядом с `display: flex` маленькая иконка с сеткой. Щёлкните.
   - Появились кнопки `justify-content` и `align-items`. Перещёлкайте их — страница меняется сразу.
   - Выберите `space-between` и `center`, перенесите в файл. У `.nav` добавьте `display: flex; gap: 16px;`.
3. **Каталог.** Ниже: `main>section.catalog>article.card*6>h2{Кофе $}+p>lorem5` → <kbd>Tab</kbd> — шесть карточек с текстом-рыбой.
   - `.catalog { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; }`.
   - Значок `grid` рядом с `<section>` в Elements → на странице линии сетки с номерами.
   - Первой карточке класс `card-hit` и `.card-hit { grid-column: span 2; }` — остальные сами перестроились.
4. **Сколько влезет.** Замените колонки на `repeat(auto-fill, minmax(200px, 1fr))`.
   - Тяните границу между страницей и DevTools вверх-вниз или сужайте окно — колонок становится 4, 3, 2, 1.
5. **Макет.** Оберните всё в `div.page`, добавьте `aside` с тремя ссылками.
   - `.page { display: grid; grid-template-columns: 200px 1fr; grid-template-areas: "header header" "aside main"; gap: 16px; }` и `grid-area` каждой части.
   - Layout → Grid overlays → Show area names: на странице подписаны области `header`, `aside`, `main`.
6. **Поверх.** В первую карточку добавьте `span.badge{−20%}`.
   - `.card { position: relative; }` и `.badge { position: absolute; top: 8px; right: 8px; }`. Уберите relative — значок улетел, верните.
   - `.header { position: sticky; top: 0; background: #fff; z-index: 10; }` — прокрутите страницу, шапка осталась наверху.
   - `.card { transition: transform 0.2s; } .card:hover { transform: translateY(-4px); }` — наведите на карточки.

**Рассказать:** правило из урока — одна линия Flexbox, сетка Grid, поверх — position. Значки `flex` и `grid` в Elements — первое, куда смотреть, когда раскладка ведёт себя странно.
