Что открыть заранее: слайды, текст урока (песочницы «Кто победит?» и «box-sizing»), VS Code с домашкой, Chrome с DevTools.

Цель занятия: ученик подключает CSS, пишет правила с классами, объясняет, почему победило одно из правил, и находит стили элемента в DevTools.

## Титульный слайд (1 мин)

**На слайде:** название урока.

**Рассказать:** сегодня страницы из прошлых уроков станут красивыми.

## HTML — что есть, CSS — как выглядит (1 мин)

**На слайде:** тезис.

**Рассказать:** вспомнить кнопку из урока 1: без CSS она серая, но работает.

## Подключаем стили (4 мин)

**На слайде:** тег link и дерево с папкой css.

**Показать вживую:** ученик создаёт `css/style.css` в рецепте, подключает, пишет `body { background: pink; }` — видно, что файл подключился. Путь в href — как в прошлом уроке.

## Анатомия правила (4 мин)

**На слайде:** селектор, свойство, значение.

**Показать вживую:** удалить точку с запятой — следующее объявление перестало работать. Biome подсветит.

## Селекторы (6 мин)

**На слайде:** таблица селекторов.

**Показать вживую:** песочница «Классы и состояния»: навести мышь на ссылку, поменять цвет карточки.

**Спросить:** «Как выбрать только ссылки в подвале, но не в меню?» Ответ: `footer a`.

## Имена классов (3 мин)

**На слайде:** правила именования.

**Рассказать:** `.red-text` — плохо: завтра дизайнер сделает его синим. Класс описывает, что это, а не как выглядит.

## Цвета и единицы (5 мин)

**На слайде:** две таблицы.

**Рассказать:** цвета берём из макета в HEX. Шрифты и отступы — в rem, рамки — в px.

**Показать вживую:** ⌘+ в браузере: rem-текст увеличивается вместе со страницей.

## Текст (5 мин)

**На слайде:** шрифтовой стек, line-height, ширина строки.

**Показать вживую:** песочница «Типографика»: убрать `max-width: 60ch` — строки стали длинными, читать тяжело.

## Каскад: кто победит (7 мин)

**На слайде:** шкала веса: тег, класс, id, style.

**Рассказать:**
- Сначала сравниваем вес. Только при равном весе смотрим на порядок.
- Поэтому стили — классами: их легко перебить другим классом.

## Проверим (5 мин)

**На слайде:** три правила для одного абзаца.

**Показать вживую:** после ответа ученика открыть песочницу «Кто победит?» и проверить.

**Спросить:** ученик предсказывает цвет до запуска. Потом удалить #promo, поменять порядок правил и снова предсказать.

## Наследование (3 мин)

**Рассказать:** цвет и шрифт задаём один раз на body. Рамку у body дети не получат.

## Блочная модель (7 мин)

**На слайде:** вложенные слои margin, border, padding, content.

**Показать вживую:** DevTools → Computed на карточке: та же схема, в тех же цветах. Навести на слои — они подсвечиваются на странице.

## box-sizing (6 мин)

**На слайде:** расчёт 350px и исправление.

**Показать вживую:** песочница «box-sizing». Ученик сам считает ширину первого блока.

**Спросить:** «Зачем писать box-sizing для всех элементов, а не только для карточки?» Ответ: чтобы все размеры считались одинаково.
