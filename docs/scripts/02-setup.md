Что открыть заранее: слайды, текст урока, Терминал. Попросите ученика прийти с зарядкой и паролем от своего Mac — без пароля Node.js и Git не установятся.

Цель занятия: к концу у ученика установлены Chrome, VS Code, Node.js и Git, он уверенно выполняет `pwd`, `ls`, `cd`, `mkdir` и понимает, что такое путь.

Формат: половина занятия — установка на экране ученика. Ученик делает сам, вы подсказываете, руками за него не нажимаете.

**Рассказать:**

- Попросите ученика включить демонстрацию экрана.

**Рассказать:**

## Пять программ фронтенд-разработчика (3 мин)

**На слайде:** VS Code → Chrome → Node.js → Git и пояснение «Терминал уже есть».

**Рассказать:**
- VS Code — где пишем, Chrome — где смотрим, Node.js — запускает инструменты, Git — хранит историю.
- Сразу поставим всё, хотя Node.js и Git понадобятся позже.

## Клавиши Mac (3 мин)

**На слайде:** таблица значков ⌘ ⌥ ⇧ ⌃.

**Рассказать:**

**Спросить:** «Где у вас на клавиатуре Option?» Пусть ученик найдёт все четыре клавиши.

## Finder: настоящие имена файлов (4 мин)

**На слайде:** путь до настройки расширений и строки пути.

**Показать вживую:** ученик сам включает обе настройки у себя. Проверьте: в Загрузках видны `.pkg`, `.dmg`, `.zip`.

**Рассказать:** иначе однажды появится `index.html.txt`, и страница откроется как текст.

## Папка для учёбы: ~/dev (2 мин)

**На слайде:** дерево папок с выделенной `dev`.

**Рассказать:**
- `~` — домашняя папка. Всё учебное — в `~/dev`.
- Почему не Рабочий стол: iCloud, пробелы, кириллица.

## Что такое Терминал (4 мин)

**На слайде:** одни и те же действия в Finder мышью и в Терминале командами.

**Рассказать:**
- Терминал — тот же Finder, только текстом. Любое действие мышью можно сделать командой.
- Зачем: `npm`, `git`, Vite работают только через команды. Без Терминала их не запустить.
- Терминал — окно, zsh — оболочка внутри, которая выполняет команды.

## Как выглядит Терминал (4 мин)

**На слайде:** окно Терминала сразу после запуска с метками 1 и 2.

**Показать вживую:** ученик открывает Терминал через Spotlight, закрепляет его в Dock, увеличивает шрифт ⌘+.

**Рассказать:** строку Last login не читаем, главное — приглашение и курсор.

## Приглашение (3 мин)

**На слайде:** из чего состоит приглашение: пользователь, папка, `%`.

**Рассказать:** приглашение всегда показывает текущую папку — это главная подсказка, где вы находитесь.

**Спросить:** «В какой вы сейчас папке?» Ученик должен ответить по приглашению, а не по памяти.

## Как устроена команда (5 мин)

**На слайде:** `ls -a ~/dev`: имя команды, флаг, аргумент.

**Рассказать:**
- Команда — строка из частей через пробел.
- Флаг — как сделать, аргумент — с чем.

**Показать вживую:** `ls`, потом `ls -a` в домашней папке. Откуда взялись файлы с точкой? Это скрытые настройки программ.

## Четыре правила (4 мин)

**На слайде:** регистр, пробелы, тишина при успехе, чтение ошибок; пример ошибки `cd dve`.

**Показать вживую:** ученик специально делает опечатку `cd dve`, читает ошибку вслух и исправляет через ↑.

## Команды: где я и куда иду (6 мин)

**На слайде:** `pwd`, `ls`, `cd`, `..`, `~` и клавиши Tab, ↑, ⌃C.

**Показать вживую:** ученик вводит команды сам, после каждой — `pwd`. Попробовать Tab на длинном имени папки.

**Спросить:** «Как вернуться в домашнюю папку одной командой?» Ответ: `cd ~` или просто `cd`.

## Команды: файлы и папки (5 мин)

**На слайде:** `mkdir`, `touch`, `cp`, `mv`, `rm`, `open`, `code`.

**Рассказать:**
- `rm` удаляет без Корзины — всегда проверяем, что написано после `rm`.
- `code .` заработает, когда поставим VS Code.

## Попробуем вместе (6 мин)

**На слайде:** сеанс: создаём `~/dev/hello` с файлом `index.html` и открываем папку.

**Показать вживую:** ученик повторяет сеанс у себя, в конце `open .` открывает ту же папку в Finder.

## Пути (6 мин)

**На слайде:** дерево `dev/hello` с пометками `.` и `..`.

**Рассказать:**
- Абсолютный путь — от корня, работает отовсюду. Относительный — от текущей папки.
- В HTML будет то же самое: ссылки на картинки и стили.

**Спросить:** «Вы в `hello`. Какой относительный путь до `shop/index.html`?» Ответ: `../shop/index.html`.

## Как ставятся программы на Mac (2 мин)

**На слайде:** скачать → открыть → перетащить в «Программы» → запустить.

**Рассказать:**
- Почти все программы для Mac ставятся так. Предупреждение «загружено из интернета» — нормально для официальных сайтов.

## Chrome (2 мин)

**На слайде:** скриншот google.com/chrome с кнопкой.

**Показать вживую:** ученик ставит Chrome, если его ещё нет. Можно сделать браузером по умолчанию — по желанию.

## VS Code (6 мин)

**На слайде:** кнопка Mac на сайте и три шага: распаковать, перенести, установить команду `code`.

**Показать вживую:**
1. Скачать, распаковать, перетащить в «Программы».
2. Запустить, нажать «Открыть».
3. ⇧⌘P → `Shell Command: Install 'code' command in PATH`.
4. В Терминале: `cd ~/dev` и `code .` — открылась папка.

**Рассказать:** интерфейс VS Code разберём на следующем уроке, сегодня только ставим.

**Показать вживую:** пройти установщик до «Закрыть».

**На слайде:** команда `xcode-select --install` и скриншот сайта Git.

**Показать вживую:** ученик вставляет команду, в окне нажимает «Установить». Пока идёт загрузка (5–15 минут), переходите к следующему слайду и возвращайтесь к проверке в конце.

**Рассказать:** Git на Mac входит в инструменты разработчика от Apple, отдельно качать не нужно.
