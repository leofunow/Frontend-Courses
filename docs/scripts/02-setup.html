Модуль 0. Старт/Урок 2/Сценарий

Сценарий к слайдам

Рабочее место на Mac. Что на каждом слайде и что рассказать.

100 мин24 слайда Открыть слайды Скачать .md Текст урока Правки к занятию

Перед занятием

Что открыть заранее: слайды, текст урока, Терминал. Попросите ученика прийти с зарядкой и паролем от своего Mac — без пароля Node.js и Git не установятся.

Цель занятия: к концу у ученика установлены Chrome, VS Code, Node.js и Git, он уверенно выполняет pwd, ls, cd, mkdir и понимает, что такое путь.

Формат: половина занятия — установка на экране ученика. Ученик делает сам, вы подсказываете, руками за него не нажимаете.

1

Титульный слайд

2 мин

На слайде: название урока.

Рассказать:

  • Сегодня практическое занятие: всё ставим на ваш Mac и проверяем.
  • Попросите ученика включить демонстрацию экрана.
2

Сегодня собираем рабочее место

1 мин

На слайде: тезис.

Рассказать:

  • Правильно настроенное рабочее место избавит от десятков странных ошибок в будущем.
3

Пять программ фронтенд-разработчика

3 мин

На слайде: VS Code → Chrome → Node.js → Git и пояснение «Терминал уже есть».

Рассказать:

  • VS Code — где пишем, Chrome — где смотрим, Node.js — запускает инструменты, Git — хранит историю.
  • Сразу поставим всё, хотя Node.js и Git понадобятся позже.
4

Клавиши Mac

3 мин

На слайде: таблица значков ⌘ ⌥ ⇧ ⌃.

Рассказать:

  • В курсе и в документации сочетания пишут значками. Command и Control — разные клавиши.

Спросить: «Где у вас на клавиатуре Option?» Пусть ученик найдёт все четыре клавиши.

5

Finder: настоящие имена файлов

4 мин

На слайде: путь до настройки расширений и строки пути.

Показать вживую: ученик сам включает обе настройки у себя. Проверьте: в Загрузках видны .pkg, .dmg, .zip.

Рассказать: иначе однажды появится index.html.txt, и страница откроется как текст.

6

Папка для учёбы: ~/dev

2 мин

На слайде: дерево папок с выделенной dev.

Рассказать:

  • ~ — домашняя папка. Всё учебное — в ~/dev.
  • Почему не Рабочий стол: iCloud, пробелы, кириллица.
7

Что такое Терминал

4 мин

На слайде: одни и те же действия в Finder мышью и в Терминале командами.

Рассказать:

  • Терминал — тот же Finder, только текстом. Любое действие мышью можно сделать командой.
  • Зачем: npm, git, Vite работают только через команды. Без Терминала их не запустить.
  • Терминал — окно, zsh — оболочка внутри, которая выполняет команды.

4 мин

Показать вживую: ученик открывает Терминал через Spotlight, закрепляет его в Dock, увеличивает шрифт ⌘+.

Рассказать: строку Last login не читаем, главное — приглашение и курсор.

23

Воркшоп: проект из Терминала

14 мин

На слайде: шесть шагов: от открытия Терминала до удаления файла.

Подготовить заранее: закройте все окна Терминала. Откройте Finder с папкой ~/dev — будем сравнивать Finder и Терминал. Увеличьте шрифт Терминала для экрана: ⌘++ два-три раза.

Показать вживую:

  1. Открыть Терминал. ⌘+Пробел → наберите «Терминал» → Enter.
    • Покажите приглашение mary@MacBook-Air ~ %: имя, компьютер, текущая папка ~.
    • Наберите pwd → Enter: /Users/mary. Это та же домашняя папка, что в Finder слева под домиком.
  2. Перейти и создать. Наберите cd de и нажмите Tab — Терминал дописал dev/. Enter.
    • mkdir -p workshop/css → Enter. Посмотрите в Finder — появилась папка workshop, внутри css.
    • cd workshop → touch index.html css/style.css → ls -R: видно оба файла.
    • open . — откроется Finder прямо в этой папке. Вернитесь в Терминал: ⌘+Tab.
  3. В редактор. code . → Enter. Откроется VS Code с папкой workshop.
    • Если «command not found: code» — в VS Code ⇧+⌘+P → Shell Command: Install 'code' command in PATH, потом новое окно Терминала.
    • В index.html напишите <h1>Мастерская</h1> → ⌘+S.
  4. В браузер. В Терминале: open -a "Google Chrome" index.html.
    • В адресной строке виден file:///Users/mary/dev/workshop/index.html — абсолютный путь к файлу.
    • Просто open index.html откроет браузер по умолчанию — на Mac это часто Safari.
  5. Файлы без Finder.
    • cp index.html about.html → ls: файлов два.
    • mv about.html contacts.html → ls: переименовался.
    • rm contacts.html → ls: пропал. Подчеркните: rm удаляет насовсем, мимо Корзины.
  6. Ошибиться нарочно.
    • nmp -v → command not found: nmp. Нажмите ↑ — вернулась прошлая команда, исправьте на npm -v.
    • cd nowhere → no such file or directory. Читаем ошибку по словам: чего нет и где.
    • ping ya.ru работает бесконечно → ⌃+C останавливает. ⌘+K очищает экран.
  7. Проверка установки. node -v && npm -v && git --version && code --version — четыре версии, как в первом задании.

Рассказать: Терминал — это тот же Finder, только словами. Каждую команду можно проверить глазами в Finder, пока не привыкнете.

Домашнее задание

3 мин

На слайде: пять заданий.

Рассказать:
