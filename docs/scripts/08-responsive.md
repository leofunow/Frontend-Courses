Что открыть заранее: слайды, текст урока (песочницы), VS Code с домашкой, Chrome с DevTools. Если есть телефон — сайт курса или любая страница ученика по Live Server в одной Wi-Fi-сети.

Цель занятия: ученик проверяет страницу в режиме устройств, пишет медиазапросы по принципу mobile-first и убирает фиксированные ширины.

**На слайде:** название урока.

**Рассказать:** до сих пор всё верстали под ноутбук. Сегодня научим страницы жить на телефоне.

**На слайде:** строка viewport и два скриншота.

## Воркшоп: адаптируем свою страницу (20 мин)

**На слайде:** шесть шагов: от проверки в режиме устройств до настоящего телефона.

**Подготовить заранее:** `catalog.html` с прошлого урока. Добавьте в него блок `div.promo` с `width: 600px` и картинку без `max-width` — будет что чинить. Телефон в той же Wi-Fi, что и Mac.

**Показать вживую:**
1. **Режим устройств.** Откройте страницу через Go Live → <kbd>⌥</kbd>+<kbd>⌘</kbd>+<kbd>I</kbd> → <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>M</kbd>.
   - Сверху Dimensions → iPhone SE. Потом Responsive и тяните правый край страницы — ширина видна в поле.
   - ⋮ справа на панели устройства → Show media queries — появятся цветные полоски, пока пустые.
2. **Что вылезает.** На ширине 375 внизу появилась горизонтальная прокрутка.
   - Кнопка со стрелкой (<kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>C</kbd>) → наводите на блоки: у `.promo` ширина 600 — вот он.
   - В Styles поменяйте `width` на `max-width` — прокрутка пропала. Перенесите в файл.
3. **Сначала телефон.** У `.catalog` оставьте без медиазапроса `grid-template-columns: 1fr;` — одна колонка.
4. **Медиазапросы.** В конце файла:
   - `@media (min-width: 640px) { .catalog { grid-template-columns: repeat(2, 1fr); } }`
   - `@media (min-width: 1024px) { .catalog { grid-template-columns: repeat(3, 1fr); } }`
   - <kbd>⌘</kbd>+<kbd>S</kbd> → в режиме устройств появились полоски 640 и 1024. Щёлкните по полоске — ширина встанет ровно на брейкпоинт.
   - В Styles правила внутри медиазапроса подписаны `@media (min-width: 640px)` — видно, что сработало.
5. **Резиновые размеры.**
   - `img { max-width: 100%; height: auto; display: block; }` — картинка перестала вылезать.
   - `h1 { font-size: clamp(1.75rem, 5vw, 3rem); }` — тяните ширину: заголовок плавно меняется и упирается в границы.
   - Удалите в `head` строку `meta name="viewport"` → <kbd>⌘</kbd>+<kbd>R</kbd> в режиме iPhone: страница мелкая, медиазапросы не работают. Верните.
6. **Настоящий телефон** — по желанию.
   - VS Code → <kbd>⌘</kbd>+<kbd>,</kbd> → в поиске `liveServer host` → поставьте `0.0.0.0`. Остановите и снова нажмите Go Live.
   - macOS спросит «Разрешить входящие подключения?» → Разрешить.
   - Узнайте адрес Mac: Системные настройки → Wi-Fi → Подробнее → IP-адрес, например `192.168.1.5`. На телефоне откройте `http://192.168.1.5:5500/catalog.html`.

**Рассказать:** режим устройств — быстрая проверка, но финальная — на настоящем телефоне: там другой шрифт, палец вместо мыши и нет `:hover`.
