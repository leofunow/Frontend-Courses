Сценарий к слайдам

Формы, таблицы и доступность. Что на каждом слайде и что рассказать.

Перед занятием

Что открыть заранее: слайды, текст урока (песочницы с формами), VS Code с папкой homework. Проверьте, что VoiceOver на вашем Mac включается сочетанием ⌘F5.

Цель занятия: ученик собирает форму с подписанными полями нужных типов, включает встроенную проверку, делает таблицу и проверяет страницу клавиатурой.

Спросить: «Откуда в адресе взялось слово name?» Ответ: из атрибута name поля.

16

Воркшоп: форма записи в кофейню

20 мин

На слайде: шесть шагов формы: от поля с подписью до проверки доступности.

Подготовить заранее: папка workshop-html с прошлого урока открыта в VS Code, Go Live включён. Создайте файл booking.html с каркасом (! → Tab, lang="ru").

Показать вживую:

  1. Поле и подпись. В body наберите form>label[for=name]{Имя}+input#name[name=name] → Tab.
    • В браузере щёлкните по слову «Имя» — курсор встал в поле. Это и есть связь for и id.
    • Сотрите for → щелчок по подписи ничего не делает. Верните.
  2. Типы полей. Скопируйте пару строк (⇧+⌥+↓) и поменяйте:
    • type="email" для почты, type="tel" для телефона, type="date" для даты — в Chrome появился календарь.
    • type="number" min="1" max="10" для гостей — стрелки и ограничение.
  3. Обязательные поля. Добавьте required к имени, телефону и дате. Добавьте кнопку button[type=submit]{Записаться} → Tab.
    • Нажмите «Записаться» с пустой формой — Chrome показал подсказку «Заполните это поле».
    • В email напишите mary → «Записаться»: браузер просит @. Всё это без единой строки JavaScript.
  4. Выбор и комментарий.
    • label[for=hall]{Зал}+select#hall[name=hall]>option*3 → Tab: «Основной», «Веранда», «У окна».
    • label[for=comment]{Комментарий}+textarea#comment[name=comment] → Tab.
    • Галочка: label>input[type=checkbox name=agree required]+{Согласен с правилами} → Tab.
    • Оберните поля гостей и зала в fieldset с legend{Детали брони} — рамка с подписью.
  5. Отправка. Заполните форму и нажмите «Записаться».
    • Посмотрите в адресную строку: booking.html?name=Мария&hall=…. Это параметры адреса из урока 1 — так форма передаёт данные методом GET.
    • Скажите: настоящую отправку на сервер сделаем в модуле про JavaScript и Express.
  6. Проверка доступности.
    • Щёлкните в адресную строку и нажимайте Tab: фокус идёт по полям по порядку, видна рамка. Пробел ставит галочку, Enter отправляет.
    • Правый щелчок по полю → «Просмотреть код». В правой части DevTools нажмите » → Accessibility: в строке Name — текст подписи. Уберите for у подписи — Name стал пустым.
    • ⌘+F5 — включился VoiceOver. Tab по полям: он читает подписи. Ещё раз ⌘+F5 — выключить.

Рассказать: форма без подписей для VoiceOver — это поля «редактируемый текст» без названия. Подпись нужна не для красоты.
