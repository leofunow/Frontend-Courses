Модуль 1. HTML и CSS/Урок 4/Сценарий

Сценарий к слайдам

HTML — основа страницы. Что на каждом слайде и что рассказать.

99 мин35 слайдов Открыть слайды Скачать .md Текст урока Правки к занятию

Перед занятием

Что открыть заранее: слайды, текст урока (понадобятся песочницы), VS Code с папкой homework, Chrome.

Цель занятия: ученик сам собирает страницу с каркасом, заголовками, списками, ссылками и картинкой и выбирает семантические теги.

Формат: код пишет ученик, вы только подсказываете. Всё, что показываете, ученик сразу повторяет в VS Code.

1

Титульный слайд

1 мин

На слайде: название урока.

Рассказать: сегодня первая настоящая страница. К концу занятия будет рецепт с картинкой и списками.

2

Часть 1. Что такое HTML

1 мин

На слайде: разделитель первой части.

Рассказать: начнём с того, из чего состоит любая страница.

3

Три языка браузера

2 мин

На слайде: тезис про HTML, CSS и JavaScript.

Рассказать: вспомнить кнопку из урока 1: без CSS она серая, без JS не нажимается, но без HTML её просто нет.

4

Разметка

2 мин

На слайде: код с h1, p, ul и расшифровка тегов.

Показать вживую: песочница «Текст и разметка» в тексте урока: убрать теги у списка и посмотреть, что станет.

5

Анатомия тега

3 мин

На слайде: открывающий тег с атрибутом, содержимое, закрывающий тег.

Рассказать:

  • Атрибут всегда в открывающем теге: имя="значение".
  • У одиночных тегов нет пары.

Спросить: «Что в <img src="a.png" alt="Кот"> тег, а что атрибуты?»

6

Атрибуты, которые нужны каждый день

2 мин

На слайде: четыре карточки: href, src, alt, id.

Рассказать: эти четыре атрибута встретятся сегодня в каждом задании. Остальные будем узнавать по ходу.

7

Вложенность — как коробки

3 мин

На слайде: правильная и неправильная вложенность.

Рассказать: последнее открытое закрываем первым. Браузер «чинит» ошибки молча и не так, как вы ожидаете.

8

Каркас страницы

4 мин

На слайде: минимальный каркас.

Показать вживую: ученик создаёт index.html, пишет ! + Tab, меняет lang="en" на ru, пишет свой title, открывает через Live Server — текст title на вкладке.

9

Документ — это дерево

3 мин

На слайде: дерево html → head/body.

Показать вживую: DevTools → Elements на странице ученика: то же дерево, узлы раскрываются стрелками.

10

Что ещё кладут в head

3 мин

На слайде: title, description, icon, stylesheet.

Показать вживую: найти в поиске Яндекса любой сайт: заголовок результата — это title, серый текст под ним — часто description.

11

1 мин

На слайде: разделитель второй части.

Рассказать: теперь наполняем страницу текстом.

12

Заголовки — это оглавление

3 мин

На слайде: дерево заголовков рецепта.

Рассказать: h1 — название книги, h2 — главы, h3 — параграфы внутри главы. Размер не важен, поменяем в CSS.

13

Правила заголовков

2 мин

На слайде: один h1, шесть уровней, без пропусков.

Рассказать: по заголовкам VoiceOver строит оглавление страницы, а Google — понимает, о чём она.

Спросить: «На странице h1, потом сразу h4. Что не так?» Ответ: пропущены уровни, оглавление сломано.

14

Выделение в тексте

3 мин

На слайде: таблица тегов форматирования: код и результат.

Показать вживую: ученик добавляет в рецепт strong на время приготовления и em на «не торопиться».

15

strong и b

2 мин

На слайде: тезис про смысл и вид.

Рассказать: VoiceOver выделит strong голосом, а b прочитает как обычный текст. Жирный «для красоты» — задача CSS.

16

На слайде: ul и ol рядом.

Спросить: «Меню кофейни — какой список? А инструкция по сборке шкафа?»

2 мин

Рассказать: третий вид списка — пары «термин — описание». Пригодится для меню с описаниями и характеристик товара.

34

Воркшоп: сайт кофейни из двух страниц

20 мин

На слайде: четыре карточки: каркас, картинка, ссылки, проверка.

Подготовить заранее: любая фотография кофе в папке «Загрузки», например coffee.jpg. Закройте VS Code. Chrome с пустой вкладкой.

Показать вживую:

  1. Папка и каркас. VS Code → File → Open Folder → dev → New Folder → workshop-html → Open.
    • В проводнике New File → index.html. ! → Tab.
    • lang="ru", в <title> — «Кофейня „Зерно“». Проговорите: title — текст на вкладке, не на странице.
  2. Семантика. Внутри body наберите header>nav>a*3 → Tab, затем main, затем footer.
    • В ссылки впишите «Главная», «О нас», «Меню». href у первой — index.html, у второй — about.html.
    • В main: h1{Кофейня «Зерно»}+p → Tab, одна фраза о кофейне.
    • Ниже: h2{Меню}+ul>li*3 → Tab, три напитка.
  3. Картинка. В проводнике New Folder → img. Перетащите coffee.jpg из Finder прямо на папку img в проводнике VS Code.
    • В main наберите img → Tab. В src="" начните печатать img/ — VS Code подскажет файл, выберите.
    • В alt — что на фото: «Чашка капучино на деревянном столе». Не «картинка» и не «фото».
  4. Вторая страница. Правый щелчок по index.html → Copy, правый щелчок по пустому месту проводника → Paste → переименуйте копию в about.html (Enter на файле).
    • В about.html поменяйте h1 на «О нас», уберите меню напитков.
    • Справа внизу Go Live → откроется главная. Щёлкните «О нас» → «Главная»: ссылки работают в обе стороны.
  5. Ломаем ссылку. В index.html поменяйте about.html на abuot.html → ⌘+S → щёлкните ссылку в браузере: «Cannot GET /abuot.html».
    • Скажите: 404 из урока 1 — вот он. Верните правильное имя.
  6. Проверка.
    • Удалите у картинки alt → волнистая линия Biome → ⇧+⌘+M — ошибка в Problems. Верните alt.
    • В Chrome ⌥+⌘+I → Elements: раскройте body — видно header, main, footer. Наведите на main — на странице подсветилась его область.
    • Удалите в коде закрывающий </li> у одного пункта и посмотрите в Elements: браузер достроил дерево сам — поэтому ошибки в HTML «незаметны», но Biome их видит.

Рассказать: это и есть задание 2 домашки, только про свою кофейню. Ученик делает то же самое по шагам, со своими текстами и картинками.
