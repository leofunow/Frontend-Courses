Что открыть заранее: слайды, текст урока (понадобятся песочницы), VS Code с папкой `homework`, Chrome.

Цель занятия: ученик сам собирает страницу с каркасом, заголовками, списками, ссылками и картинкой и выбирает семантические теги.

Формат: код пишет ученик, вы только подсказываете. Всё, что показываете, ученик сразу повторяет в VS Code.

## Воркшоп: сайт кофейни из двух страниц (20 мин)

**На слайде:** шесть шагов: от каркаса до проверки.

**Подготовить заранее:** любая фотография кофе в папке «Загрузки», например `coffee.jpg`. Закройте VS Code. Chrome с пустой вкладкой.

**Показать вживую:**
1. **Папка и каркас.** VS Code → File → Open Folder → `dev` → New Folder → `workshop-html` → Open.
   - В проводнике New File → `index.html`. <kbd>!</kbd> → <kbd>Tab</kbd>.
   - `lang="ru"`, в `<title>` — «Кофейня „Зерно“». Проговорите: title — текст на вкладке, не на странице.
2. **Семантика.** Внутри `body` наберите `header>nav>a*3` → <kbd>Tab</kbd>, затем `main`, затем `footer`.
   - В ссылки впишите «Главная», «О нас», «Меню». `href` у первой — `index.html`, у второй — `about.html`.
   - В `main`: `h1{Кофейня «Зерно»}+p` → <kbd>Tab</kbd>, одна фраза о кофейне.
   - Ниже: `h2{Меню}+ul>li*3` → <kbd>Tab</kbd>, три напитка.
3. **Картинка.** В проводнике New Folder → `img`. Перетащите `coffee.jpg` из Finder прямо на папку `img` в проводнике VS Code.
   - В `main` наберите `img` → <kbd>Tab</kbd>. В `src=""` начните печатать `img/` — VS Code подскажет файл, выберите.
   - В `alt` — что на фото: «Чашка капучино на деревянном столе». Не «картинка» и не «фото».
4. **Вторая страница.** Правый щелчок по `index.html` → Copy, правый щелчок по пустому месту проводника → Paste → переименуйте копию в `about.html` (<kbd>Enter</kbd> на файле).
   - В `about.html` поменяйте `h1` на «О нас», уберите меню напитков.
   - Справа внизу Go Live → откроется главная. Щёлкните «О нас» → «Главная»: ссылки работают в обе стороны.
5. **Ломаем ссылку.** В `index.html` поменяйте `about.html` на `abuot.html` → <kbd>⌘</kbd>+<kbd>S</kbd> → щёлкните ссылку в браузере: «Cannot GET /abuot.html».
   - Скажите: 404 из урока 1 — вот он. Верните правильное имя.
6. **Проверка.**
   - Удалите у картинки `alt` → волнистая линия Biome → <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>M</kbd> — ошибка в Problems. Верните `alt`.
   - В Chrome <kbd>⌥</kbd>+<kbd>⌘</kbd>+<kbd>I</kbd> → Elements: раскройте `body` — видно `header`, `main`, `footer`. Наведите на `main` — на странице подсветилась его область.
   - Удалите в коде закрывающий `</li>` у одного пункта и посмотрите в Elements: браузер достроил дерево сам — поэтому ошибки в HTML «незаметны», но Biome их видит.

**Рассказать:** это и есть задание 2 домашки, только про свою кофейню. Ученик делает то же самое по шагам, со своими текстами и картинками.
