Модуль 0. Старт/Урок 2 из 33

Рабочее место на Mac

Терминал, установка программ, пути и папки

90 минут теории, 1–1,5 часа заданийСлайды к урокуСценарий к слайдам

После урока вы сможете

  • Открыть Терминал и перемещаться по папкам командами
  • Установить Chrome, VS Code, Node.js и Git с официальных сайтов
  • Проверить установку и починить типичные проблемы
  • Настроить Finder так, чтобы видеть настоящие имена файлов

Урок за минуту

  • Терминал — окно, где вы даёте компьютеру команды текстом
  • Учебные файлы храним в папке ~/dev: в путях только латиница и никаких пробелов
  • Chrome, VS Code и Node.js ставим с официальных сайтов, Git — одной командой в Терминале
  • Node.js даёт сразу две программы: node и npm
  • Терминал не видит только что установленную программу — закройте его (⌘Q) и откройте снова

Что установим и зачем

Для работы фронтенд-разработчику нужны пять программ. Терминал уже есть на Mac, остальные ставим сегодня.

Программа Зачем Понадобится
Терминал Давать компьютеру команды текстом сегодня
Chrome Браузер с лучшими инструментами разработчика с урока 1
VS Code Редактор кода с урока 3
Node.js Запускает JavaScript вне браузера, ставит пакеты через npm с урока 10
Git Сохраняет историю изменений кода с урока 9

Клавиши Mac

В курсе сочетания клавиш записаны по-маковски. Запомните четыре значка:

Значок Клавиша Пример
⌘ Command (Cmd) ⌘+C — копировать
⌥ Option (Alt) ⌥+⌘+I — DevTools
⇧ Shift ⇧+⌘+P — палитра команд в VS Code
⌃ Control ⌃+C — остановить команду в Терминале

Сочетания, которые нужны каждый день:

Сочетание Что делает
⌘+Пробел Spotlight: найти и открыть программу по имени
⌘+Tab Переключиться между программами: VS Code ↔ Chrome ↔ Терминал
⌘+` Переключиться между окнами одной программы
⌘+Q Закрыть программу целиком. Красный кружок закрывает только окно
⌘+, Настройки любой программы
⇧+⌘+4 Скриншот области. С ⌃ — сразу в буфер обмена
⇧+⌘+5 Панель скриншотов и запись экрана — показать ментору, что происходит

Command и Control — разные клавиши

В Терминале ⌃+C (Control) останавливает команду, а ⌘+C (Command) копирует текст. Путать их не страшно, но результат будет разным.

Finder: видеть настоящие имена файлов

По умолчанию Mac прячет расширения файлов: вместо index.html вы видите index. Это ловушка — файл может оказаться index.html.txt, и браузер покажет его как текст. Включите расширения и строку пути.

Скрытые файлы

Файлы, чьё имя начинается с точки (.gitignore, .env), Finder не показывает. Показать или спрятать их — ⇧+⌘+. в любом окне Finder.

Папка для учёбы

Все учебные проекты храните в одной папке dev внутри домашней папки. Короткий путь без пробелов и русских букв избавит от половины странных ошибок.

«Мои проекты» на Рабочем столе

Папки «Рабочий стол» и «Документы» часто синхронизируются с iCloud: файлы могут пропасть или раздвоиться. Пробелы и кириллица в пути ломают команды в Терминале. Правильно: ~/dev/my-project.

Терминал: что это и зачем

Терминал — программа, где вы управляете компьютером текстом: пишете команду, нажимаете Return, компьютер отвечает. Это тот же Finder, только без мыши.

Зачем фронтенд-разработчику Терминал, если есть мышь? Многие инструменты работают только через команды: npm ставит библиотеки, git сохраняет историю, Vite запускает проект. Без Терминала их не запустить.

Терминал и zsh

Терминал — это окно. Внутри работает оболочка zsh: она понимает команды и выполняет их. Поэтому в ошибках часто пишут zsh: ….

Как выглядит Терминал

Откройте Терминал: ⌘+Пробел, наберите «Терминал», нажмите Return. Появится такое окно:

  1. Служебная строка: когда вы последний раз открывали Терминал. На неё не обращайте внимания.
  2. Приглашение — Терминал ждёт команду. Мигающий курсор — место, куда вы печатаете.

Приглашение подсказывает, кто вы и где находитесь:

Удобнее с первого дня

  • Закрепите Терминал в Dock: правый клик по значку → Параметры → Оставить в Dock.
  • Шрифт крупнее: ⌘++, мельче: ⌘+−.
  • Новое окно — ⌘+N, новая вкладка — ⌘+T.

Как устроена команда

Команда — это строка из частей, разделённых пробелами. Сначала имя команды, потом флаги (настройки с дефисом), потом аргументы — над чем работать.

Правила, которые стоит запомнить сразу:

  • Регистр букв. Команды пишут маленькими буквами: ls, cd. Mac в именах файлов регистр прощает: cd Dev откроет папку dev. Сервер и GitHub Pages — не прощают. Поэтому имена сразу пишите точно и маленькими буквами.
  • Пробел разделяет части. cd my folder — это попытка перейти в папку my. Имя с пробелом берут в кавычки: cd "my folder".
  • Нет ответа — значит, всё хорошо. Команды вроде mkdir и cd молчат при успехе.
  • Ошибку нужно прочитать. Терминал пишет, что пошло не так:

Клавиши, которые экономят время

  • Tab дописывает имя: наберите cd De и нажмите Tab.
  • ↑ и ↓ листают прошлые команды.
  • ⌃+C останавливает команду, которая «зависла».
  • ⌘+K очищает экран.
  • Перетащите папку из Finder в окно Терминала — вставится её полный путь.
  • ⌥+щелчок по строке команды переносит курсор туда, куда щёлкнули. ⌃+A и ⌃+E — в начало и конец строки.

Скопировали команду вместе с приглашением

В инструкциях команды часто показывают с приглашением: mary@MacBook-Air ~ % ls. Копировать нужно только то, что после %. Иначе Терминал попытается выполнить ваше имя:

Основные команды

Этих команд хватит на весь курс. Попробуйте каждую прямо сейчас.

Команда Что делает Пример
pwd Показывает, в какой папке вы сейчас pwd → /Users/mary
ls Список файлов и папок. -a — со скрытыми, -l — подробно ls -la
cd Перейти в папку. .. — на уровень выше, ~ — домой cd ~/dev
mkdir Создать папку. -p — сразу со вложенными mkdir -p site/css
touch Создать пустой файл touch index.html
open Открыть в программе по умолчанию. . — эта папка в Finder open index.html
code Открыть в VS Code (заработает после установки) code .
cp Скопировать файл cp a.html b.html
mv Переместить или переименовать mv b.html about.html
rm Удалить файл без Корзины rm about.html
clear Очистить экран clear

Так выглядит первое знакомство целиком: создаём папку для учёбы и смотрим, что получилось.

rm удаляет навсегда

Файл, удалённый через rm, не попадает в Корзину. Проверяйте, что стоит после rm, прежде чем нажать Return. Никогда не запускайте rm -rf с путями из интернета.

Как узнать больше о команде

man ls открывает справку по команде ls. Листать — пробелом, выйти — клавишей Q.

Пути: абсолютные и относительные

Путь — адрес файла. Он бывает двух видов.

  • Абсолютный — от корня диска: /Users/mary/dev/hello/index.html. Работает, где бы вы ни находились. ~ — то же, что /Users/mary.
  • Относительный — от текущей папки: если вы в dev, тот же файл — hello/index.html.

Эти же правила действуют в HTML: ссылки на картинки и стили будут относительными путями (урок 4).

Установка Chrome

Chrome — основной браузер курса: его DevTools используют почти все фронтенд-разработчики. Откройте google.com/chrome в Safari.

Какой у меня Mac

Меню Apple — яблоко в левом верхнем углу экрана → Об этом Mac → строка «Чип»: Apple M1–M4 или Intel. Сайты из этого урока сами дают версию, которая подходит обоим. Но если на сайте просят выбрать — выбирайте по этой строке: Apple Silicon или Intel.

Программы для Mac устанавливаются одинаково: скачали, открыли, перетащили в «Программы».

При первом запуске macOS предупредит, что приложение загружено из интернета, и спросит, открыть ли его. Нажмите «Открыть»: вы скачали его с официального сайта.

Установка VS Code

Откройте code.visualstudio.com/download и нажмите кнопку для Mac.

  1. В «Загрузках» появится архив .zip. Дважды щёлкните — рядом появится программа Visual Studio Code.
  2. Перетащите её в папку «Программы» в боковой панели Finder.
  3. Запустите VS Code через Spotlight и нажмите «Открыть» в предупреждении.

Теперь научим Терминал открывать VS Code командой code. В VS Code нажмите ⇧+⌘+P, начните вводить shell command и выберите Shell Command: Install 'code' command in PATH.

VS Code запущен прямо из «Загрузок»

Так он работает, но не обновляется, а команда code потом ломается. Сначала перетащите программу в «Программы», потом запускайте.

Установка Node.js

Откройте nodejs.org/en/download. Проверьте, что выбрана версия с меткой LTS — стабильная, с долгой поддержкой.

Прокрутите ниже и скачайте установщик для macOS. Блок с командами в середине страницы пропустите: он для другого способа установки.

Откройте скачанный .pkg: «Продолжить» → «Продолжить» → «Принять» → «Установить» → пароль от Mac → «Закрыть». Вместе с Node.js установится npm.

Установка Git

На Mac Git входит в набор инструментов разработчика от Apple (Command Line Tools). Его рекомендует и официальный сайт Git.

Вставьте команду в Терминал:

Появится окно с предложением установить инструменты разработчика командной строки. Нажмите «Установить», затем «Принять». Загрузка займёт 5–15 минут.

Если появилось «command line tools are already installed»

Значит, инструменты уже стоят — пропускайте шаг.

Проверка установки

Закройте Терминал (⌘+Q), откройте заново и выполните четыре команды. Каждая должна напечатать номер версии. Цифры у вас будут другие — это нормально.

Если видите Что делать
zsh: command not found: node Закройте Терминал через ⌘Q и откройте снова. Не помогло — переустановите Node.js
zsh: command not found: code Выполните в VS Code команду Shell Command: Install 'code' command in PATH
окно с предложением установить инструменты Это Git просит Command Line Tools — нажмите «Установить»

Частые ошибки

Файл сохранился как index.html.txt

Так бывает, если писать код в «TextEdit». Пишите только в VS Code и включите показ расширений в Finder.

«Не удаётся открыть приложение»

macOS не пускает программу, если не уверена в разработчике. Если вы скачали её с официального сайта: Системные настройки → Конфиденциальность и безопасность → внизу сообщение об этой программе → «Всё равно открыть». Программы из непонятных источников так открывать нельзя.

sudo перед командой

Советы из интернета вида sudo npm install … дают команде права администратора. В курсе это не нужно, а права на папки потом ломаются. Если команда требует sudo — спросите ментора.

Пробел в пути без кавычек

cd Мои проекты Терминал поймёт как две папки. Если без пробела никак — берите путь в кавычки: cd "Мои проекты". А лучше переименуйте папку.

Квиз

Квиз: 10 вопросов
  1. 1. Вы открыли Терминал и видите mary@MacBook-Air dev %. Что это значит?
    Это приглашение. Перед % — имя текущей папки, после % можно вводить команду.
  2. 2. Что в команде ls -a ~/dev является флагом?
    Флаг — настройка команды, начинается с дефиса. ls — имя команды, ~/dev — аргумент, с чем работать.
  3. 3. Терминал ответил cd: no such file or directory: dve. Что это значит?
    Терминал ищет папку там, где вы сейчас. Проверьте ls, какие папки есть на самом деле, и допишите имя клавишей Tab.
  4. 4. Какая команда покажет полный путь к текущей папке?
    pwd — print working directory. ls показывает содержимое папки, а не её путь.
  5. 5. Вы в папке ~/dev/hello. Куда попадёте после cd ..?
    Две точки — папка уровнем выше. Выше hello находится dev.
  6. 6. Какой путь абсолютный?
    Абсолютный путь начинается от корня: с / или ~. Остальные считаются от текущей папки.
  7. 7. Какую версию Node.js выбрать на сайте?
    LTS — стабильная версия с долгой поддержкой. Её выбирают для работы и учёбы.
  8. 8. Вы установили Node.js, но Терминал пишет command not found: node. Что сделать первым?
    Терминал узнаёт о новых программах при запуске. В большинстве случаев достаточно его перезапустить.
  9. 9. Вы скопировали из инструкции строку mary@MacBook-Air ~ % pwd целиком. Терминал ответил command not found: mary@MacBook-Air. Что не так?
    Приглашение Терминал рисует сам. Команда — только то, что после знака %.
  10. 10. Зачем включать показ расширений в Finder?
    Mac прячет расширения. Файл может называться иначе, чем вы думаете, и браузер откроет его неправильно.
