Глоссарий

Все термины курса. В тексте уроков они подчёркнуты пунктиром — нажмите на слово, чтобы увидеть определение.

Абсолютный путь absolute path
Путь от самого корня диска, начинается с / или ~. Работает из любой папки.
Адаптивная вёрстка responsive design
Одна страница, которая перестраивается под ширину экрана: на телефоне одна колонка, на ноутбуке — три.
Альтернативный текст alt text
Описание картинки в атрибуте alt. Его читают программы экранного доступа и показывает браузер, если картинка не загрузилась.
Аргумент argument
То, над чем работает команда: cd dev — перейти в папку dev, здесь dev — аргумент.
Атрибут attribute
Дополнительная настройка тега внутри открывающего тега: href у ссылки, src и alt у картинки.
База данных database, DB
Программа для надёжного хранения данных и быстрого поиска по ним. Например, PostgreSQL или MongoDB.
Блочная модель box model
Каждый элемент — прямоугольник из содержимого, внутреннего отступа padding, рамки border и внешнего отступа margin.
Браузер browser
Программа, которая скачивает HTML, CSS и JavaScript и превращает их в страницу. Chrome, Edge, Firefox, Safari.
Брейкпоинт breakpoint
Ширина экрана, на которой меняется вёрстка. Например, 640px — с неё карточки встают в две колонки.
Бэкенд backend
Часть приложения на сервере — логика, проверки, работа с базой данных. Пользователь её не видит.
Валидация validation
Проверка данных перед отправкой: заполнено ли поле, похоже ли на email, подходит ли число.
Ветка branch
Отдельная линия коммитов. В ветке можно работать над задачей, не трогая основную ветку main.
Главная ось main axis
Направление, в котором flex выстраивает элементы: по умолчанию слева направо. Выравнивание вдоль неё — justify-content, поперёк — align-items.
Горячие клавиши keyboard shortcuts
Сочетания клавиш для частых действий: ⌘S — сохранить, ⌘/ — закомментировать строку.
Деплой deploy
Выкладка приложения на сервер, чтобы им могли пользоваться другие.
Домашняя папка home directory
Ваша личная папка на Mac: /Users/имя. Сокращённо — ~.
Домен domain
Человекочитаемое имя сайта, например shop.ru. Для компьютера его переводит в IP-адрес DNS.
Доступность accessibility, a11y
Удобство сайта для всех, включая людей с нарушениями зрения, слуха и моторики. Сокращение a11y: между a и y 11 букв.
Индекс staging area
Список изменений, которые попадут в следующий коммит. Файлы добавляют туда командой git add.
Интернет internet
Всемирная сеть компьютеров: кабели, Wi-Fi, провайдеры. Веб, почта и мессенджеры — сервисы, которые работают поверх неё.
Каскад cascade
Правила выбора, какой стиль применится, если несколько правил спорят за одно свойство. Отсюда «каскадные» в названии CSS.
Клиент client
Тот, кто отправляет запрос. Обычно браузер или мобильное приложение.
Команда command
Строка, которую вы вводите в Терминале и отправляете клавишей Return. Например, ls — показать содержимое папки.
Коммит commit
Сохранённый снимок проекта с сообщением: что и зачем поменяли. Из коммитов складывается история.
Лендинг landing page
Одностраничный сайт, который за несколько секунд объясняет, что предлагают, и ведёт к одному действию: записаться, заказать, позвонить.
Линтер linter
Программа, которая читает код и находит ошибки и плохие практики до запуска. В курсе — Biome.
Медиазапрос media query
Условие для блока CSS: @media (min-width: 640px) { … }. Правила внутри работают только на экранах от 640px.
Медиафункция media feature
То, что медиазапрос может спросить у браузера: ширину окна, ориентацию экрана, есть ли мышь, включена ли тёмная тема. Пример — (orientation: landscape).
Метод HTTP HTTP method
Слово в начале запроса, которое говорит, что сделать: GET — получить, POST — создать, PUT и PATCH — изменить, DELETE — удалить.
Микросервисы microservices
Бэкенд из многих маленьких сервисов. Каждый отвечает за свою часть и общается с другими через API.
Монолит monolith
Бэкенд, где вся логика — одно приложение с одной базой данных.
Наследование inheritance
Часть свойств, например цвет и шрифт, передаётся от родителя детям. Рамки и отступы не наследуются.
Оболочка shell
Программа внутри Терминала, которая понимает команды и выполняет их. На Mac — zsh. Терминал — окно, оболочка — «мозг» за ним.
Относительный путь relative path
Путь от текущей папки: hello/index.html, ../style.css. Две точки .. — папка уровнем выше.
Палитра команд Command Palette
Поиск по всем командам VS Code. Открывается ⇧⌘P: начните вводить название действия.
Подпись поля label
Текст, который объясняет, что вводить в поле. Тег <label>, связывается с полем через for и id.
Позиционирование positioning
Свойство position: как элемент встаёт относительно потока и других элементов. relative, absolute, fixed, sticky.
Поле ввода input
Элемент, куда пользователь вводит данные. Чаще всего <input>, для длинного текста — <textarea>.
Поток документа normal flow
Как элементы располагаются без раскладки: блочные — друг под другом на всю ширину, строчные — в строку, как слова в тексте.
Программа экранного доступа screen reader
Программа, которая читает страницу вслух для незрячих людей. На Mac встроена VoiceOver: ⌘F5.
Протокол protocol
Правила общения программ по сети: в каком порядке и в каком формате отправлять сообщения. Для сайтов — HTTP и HTTPS.
Псевдокласс pseudo-class
Часть селектора через двоеточие: выбирает элемент по состоянию или месту. a:hover — ссылка под курсором, li:first-child — первый пункт.
Псевдоэлемент pseudo-element
Часть элемента, которой нет в HTML, но её можно оформить: ::before и ::after добавляют содержимое в начало и конец элемента.
Путь path
Адрес файла или папки на диске, например /Users/mary/dev/index.html.
Расширение файла file extension
Окончание имени после точки: .html, .css, .js. По нему программы понимают, что внутри файла.
Расширение VS Code extension
Дополнение к VS Code от сообщества или компании. Добавляет новые возможности, например Live Server.
Редактор кода code editor
Программа для написания кода с подсветкой, подсказками и проверкой ошибок. В курсе — VS Code.
Режим устройств device mode
Режим Chrome DevTools, который показывает страницу в окне заданной ширины — как на телефоне или планшете. Включается ⇧⌘M.
Репозиторий repository
Папка проекта вместе с историей изменений. История лежит в скрытой папке .git внутри проекта.
Свойство CSS CSS property
Что именно меняем у элемента: color, font-size, padding. Записывается с значением: color: brown;.
Селектор selector
Часть CSS-правила, которая говорит, к каким элементам оно относится: h1, .card, nav a.
Семантическая разметка semantic markup
Разметка тегами по смыслу: header, nav, main, footer вместо безликих div. Её понимают люди, поисковики и программы экранного доступа.
Сервер server
Компьютер или программа, которая принимает запросы и отправляет ответы. Работает круглосуточно.
Специфичность specificity
Вес селектора в споре правил. id весомее класса, класс весомее тега. При равенстве побеждает правило ниже.
Статус-код status code
Трёхзначное число в ответе сервера. 200 — всё хорошо, 404 — не найдено, 500 — ошибка сервера.
Тег tag
Метка в угловых скобках, которая говорит браузеру, что это за кусок страницы: <p> — абзац, <a> — ссылка.
Терминал Terminal
Программа, в которой компьютеру дают команды текстом. На Mac — приложение «Терминал», внутри работает оболочка zsh.
Флаг flag, option
Настройка команды, начинается с дефиса: ls -a — показать и скрытые файлы.
Фокус focus
Элемент, который сейчас принимает ввод с клавиатуры. Переход между элементами — клавиша Tab.
Форма form
Часть страницы, где пользователь вводит данные: поля, переключатели, кнопка отправки. Тег <form>.
Форматирование formatting
Автоматическая расстановка отступов и переносов в коде, чтобы его было легко читать. В курсе этим занимается Biome.
Фреймворк framework
Готовый каркас для приложения со своими правилами. React формально библиотека, но в разговоре его тоже называют фреймворком.
Фронтенд frontend
Часть приложения, которую видит пользователь и которая работает в его браузере. Строится на HTML, CSS и JavaScript.
Фулстек full-stack
Разработчик, который пишет и фронтенд, и бэкенд.
Элемент element
Тег вместе с содержимым: <p>Привет</p> — элемент абзаца.
API Application Programming Interface
Договор о том, какие запросы можно отправить программе и что она ответит. Во вебе — набор адресов на сервере, например GET /tasks.
CSS Cascading Style Sheets
Язык стилей. Описывает внешний вид — цвета, шрифты, размеры, расположение.
CSS-переменная custom property
Именованное значение в CSS: --color-accent: #bc4c00;. Используется через var(--color-accent), меняется в одном месте.
DevOps Development + Operations
Инженер, который отвечает за серверы, выкладку новых версий и стабильную работу приложения.
DevTools Developer Tools
Инструменты разработчика в браузере. На Mac открываются сочетанием ⌥⌘I. Показывают HTML, стили, запросы, ошибки.
DNS Domain Name System
«Телефонная книга» интернета — переводит домен в IP-адрес.
Emmet Emmet
Встроенный в VS Code способ писать HTML сокращениями: ul>li*3 + Tab превращается в список из трёх пунктов.
Flexbox flexible box layout
Раскладка в одну линию: ряд или колонка. Включается display: flex у родителя.
fr fraction
Единица Grid: доля свободного места. 1fr 2fr — вторая колонка вдвое шире первой.
Git Git
Система контроля версий. Запоминает историю изменений в коде и помогает работать вместе.
GitHub GitHub
Сайт, где хранят Git-репозитории: копия проекта в интернете, ревью кода и бесплатный хостинг сайтов GitHub Pages.
GitHub Pages GitHub Pages
Бесплатная публикация сайта прямо из репозитория на GitHub. Адрес вида имя.github.io/проект.
Grid grid layout
Раскладка сеткой из строк и колонок. Включается display: grid у родителя.
HTML HyperText Markup Language
Язык разметки. Описывает структуру страницы — заголовки, абзацы, кнопки, картинки.
HTTP HyperText Transfer Protocol
Правила, по которым браузер и сервер обмениваются запросами и ответами.
HTTPS HTTP Secure
HTTP с шифрованием (TLS). Посторонние не могут прочитать или подменить данные. Замок в адресной строке.
IP-адрес IP address
Числовой адрес компьютера в сети, например 185.12.3.4.
JavaScript JS
Язык программирования, который работает в браузере и отвечает за поведение страницы. На нём же пишут серверы (Node.js).
JSON JavaScript Object Notation
Текстовый формат данных: {"name": "Анна", "age": 30}. Основной язык общения фронтенда и бэкенда.
Live Server Live Server
Расширение VS Code. Открывает страницу в браузере и обновляет её при каждом сохранении файла.
LTS Long-Term Support
Версия с долгой поддержкой — стабильная, её выбирают для работы и учёбы.
Mobile-first mobile-first
Подход к вёрстке: базовые стили пишут для телефона, а медиазапросы с min-width добавляют раскладку для широких экранов.
MPA Multi-Page Application
Сайт, где каждая страница — отдельный HTML-документ с сервера. Переход — полная перезагрузка.
Node.js Node.js
Программа, которая запускает JavaScript вне браузера. Нужна для инструментов разработки и для сервера.
npm Node Package Manager
Менеджер пакетов для JavaScript. Скачивает чужой готовый код в ваш проект. Ставится вместе с Node.js.
Pull request pull request, PR
Запрос на слияние ветки в main на GitHub. В нём видно все изменения, и ментор оставляет комментарии к строкам кода.
QA Quality Assurance
Тестировщик. Проверяет, что приложение работает как задумано, и находит баги до пользователей.
rem root em
Единица размера относительно шрифта всей страницы. Обычно 1rem = 16px. Если человек увеличит шрифт в браузере, всё увеличится вместе.
SPA Single Page Application
Приложение, которое загружается один раз, а дальше JavaScript сам меняет экран и подгружает данные. Gmail, Figma.
SSR Server-Side Rendering
Сервер собирает готовый HTML с данными, а в браузере JavaScript «оживляет» страницу. Быстрый первый показ и хорошо для поиска.
Transition CSS transition
Плавный переход между значениями свойства: transition: transform 0.2s. Без него изменения при наведении происходят мгновенно.
URL Uniform Resource Locator
Полный адрес ресурса в интернете, например https://shop.ru/catalog?page=2.
