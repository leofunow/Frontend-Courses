## Селекторы

| Селектор | Что выбирает |
|---|---|
| `p` | все абзацы |
| `.card` | класс card |
| `nav a` | ссылки внутри nav |
| `h1, h2` | и то и другое |
| `a:hover` | ссылка под курсором |

---

## Имена классов

- По смыслу: `.card`, `.card-title`, `.main-nav`
- Не по виду: ~~`.red-text`~~
- Стили — классами, не по id

## Текст

```css
body {
  font-family: -apple-system, "Segoe UI", sans-serif;
  line-height: 1.5;
  color: #1f2328;
}
```

Строка — не шире 60–70 символов: `max-width: 60ch`

## Каскад: кто победит

:::use specificity

При равном весе — правило ниже в файле

## Проверим

```html
<p class="note" id="promo">Какого я цвета?</p>
```

```css
#promo { color: purple; }
.note { color: green; }
p { color: red; }
```

## Наследование

| Наследуются | Не наследуются |
|---|---|
| `color`, `font-*`, `line-height` | `margin`, `padding`, `border`, `background` |

Шрифт и цвет — один раз на `body`

## box-sizing

```css
.card { width: 300px; padding: 24px; border: 1px solid; }
```

Реальная ширина: 300 + 48 + 2 = **350px**

```css
*, *::before, *::after { box-sizing: border-box; }
```

Теперь ровно **300px**

## Частые ошибки

- Нет точки с запятой или закрывающей скобки
- Забыли точку перед классом
- Неверный путь в `href`
- `!important` вместо точного селектора

---

## Воркшоп: оформляем страницу кофейни

1. Подключить `style.css` и проверить, что работает
2. Текст: шрифт, межстрочный интервал, ширина
3. Карточка с классом, отступами и рамкой
4. Правим вживую в DevTools → Styles
5. Кто победил в каскаде и почему
6. Переносим найденное обратно в файл
