## Подключить CSS

[[CSS]] описывает внешний вид. Стили кладут в отдельный файл и подключают в `<head>`:

```html title="index.html"
<head>
  <meta charset="utf-8">
  <title>Кофейня «Зерно»</title>
  <link rel="stylesheet" href="css/style.css">
</head>
```

:::diagram id=css-files
type: tree
caption: "Стили в папке css, путь в href — от HTML-файла"
items:
  - name: zerno
    items:
      - {name: index.html, note: "`<link rel=\"stylesheet\" href=\"css/style.css\">`"}
      - name: css
        items:
          - {name: style.css, mark: true, note: все стили сайта}
:::

| Способ | Когда |
|---|---|
| Файл и `<link>` | Всегда. Один файл стилей на весь сайт |
| Тег `<style>` в `<head>` | Быстрые опыты, одна страница-пример |
| Атрибут `style="…"` | Почти никогда: такие стили трудно найти и переопределить |

## Анатомия правила

Правило CSS состоит из [[селектор|селектора]] — к чему применить — и блока объявлений в фигурных скобках.

:::diagram id=rule-anatomy
type: flow
caption: "Одно правило: все заголовки h1 — коричневые и размером 2rem"
items:
  - {title: "`h1`", text: "селектор: к каким элементам", kind: accent, icon: false}
  - {title: "`color: brown;`", text: "свойство и значение через двоеточие, в конце точка с запятой", kind: back, icon: false}
  - {title: "`font-size: 2rem;`", text: "ещё одно объявление", kind: back, icon: false}
:::

```css title="css/style.css"
h1 {
  color: brown;
  font-size: 2rem;
}
```

:::sandbox Первые правила height=300
```html
<h1>Кофейня «Зерно»</h1>
<p>Варим кофе с 8 утра.</p>
```
```css
h1 {
  color: brown;
  font-size: 2rem;
}

p {
  color: #59636e;
  font-size: 18px;
}
```
:::

Поменяйте `brown` на `tomato`, `18px` на `24px`. Удалите точку с запятой после `brown` — сломается следующее объявление. Так выглядит самая частая ошибка в CSS.

## Селекторы

[[Селектор]] выбирает элементы. Чаще всего вы будете писать классы: атрибут `class` в HTML и точка в CSS.

| Селектор | Выбирает | Пример |
|---|---|---|
| `p` | Все теги p | `p { line-height: 1.5; }` |
| `.card` | Все элементы с классом card | `<div class="card">` |
| `nav a` | Ссылки внутри nav — через пробел | только меню, не весь сайт |
| `h1, h2` | И то и другое — через запятую | общий шрифт заголовков |
| `a:hover` | Ссылку под курсором мыши | подчёркивание при наведении |
| `a:focus-visible` | Элемент в фокусе после Tab | рамка для клавиатуры |
| `#logo` | Элемент с id="logo" | для стилей лучше класс |

:::sandbox Классы и состояния height=320
```html
<nav>
  <a href="#">Меню</a>
  <a href="#">О нас</a>
</nav>
<article class="card">
  <h2 class="card-title">Капучино</h2>
  <p>220 ₽</p>
</article>
```
```css
nav a {
  margin-right: 12px;
  color: #0969da;
}

nav a:hover {
  text-decoration: none;
}

.card {
  padding: 16px;
  border: 1px solid #d1d9e0;
  border-radius: 8px;
}

.card-title {
  margin: 0 0 8px;
}
```
:::

Имена классов — по смыслу, латиницей, через дефис: `.card`, `.card-title`, `.main-nav`. Не по виду: `.red-text` устареет, как только цвет поменяют.

## Псевдоклассы: состояния и позиции

[[Псевдокласс]] пишут через двоеточие. Он выбирает элемент не по имени, а по тому, что с ним происходит или где он стоит.

Первая группа — состояния. Интерфейс должен отвечать на каждое действие, иначе непонятно, нажалась ли кнопка.

:::shot img/css-states.webp
Одна кнопка в четырёх состояниях. Каждое задаётся своим правилом
:::

```css
/* курсор над кнопкой */
.btn:hover { background: #953800; }

/* фокус с клавиатуры */
.btn:focus-visible { outline: 3px solid #0969da; outline-offset: 3px; }

/* в момент нажатия */
.btn:active { transform: translateY(2px); }
```

`:focus-visible` срабатывает, когда до элемента дошли клавишей <kbd>Tab</kbd>. Рамку фокуса нельзя убирать через `outline: none`, не нарисовав другую: без неё человек с клавиатурой теряется на странице.

Вторая группа — позиции среди соседей. Удобно для списков и таблиц:

:::shot img/css-children.webp
`:nth-child(even)` — чётные, `odd` — нечётные, `3n` — каждый третий
:::

| Псевдокласс | Выбирает |
|---|---|
| `li:first-child` | Первый пункт |
| `li:last-child` | Последний пункт |
| `tr:nth-child(even)` | Чётные строки таблицы |
| `.card:not(.sold)` | Карточки без класса `sold` |
| `input:invalid` | Поле, которое не прошло проверку |

:::sandbox Зебра и последний пункт height=300
```html
<ul class="menu">
  <li>Эспрессо — 150 ₽</li>
  <li>Капучино — 220 ₽</li>
  <li>Латте — 240 ₽</li>
  <li>Раф — 260 ₽</li>
</ul>
```
```css
.menu {
  padding: 0;
  list-style: none;
}

.menu li {
  padding: 8px 12px;
  border-bottom: 1px solid #d1d9e0;
}

.menu li:nth-child(even) {
  background: #f6f8fa;
}

.menu li:last-child {
  border-bottom: 0;
}
```
:::

Поменяйте `even` на `odd`, потом на `2`. Уберите правило `:last-child` — у последнего пункта появится лишняя линия.

:::tip Как проверить :hover, не наводя мышь
DevTools → Styles → кнопка `:hov` → галочка `:hover`. Элемент останется в этом состоянии, пока галочку не снимут.

:::shot img/css-devtools-hov.webp width=640
Принудительное состояние в DevTools. Картинка из документации Chrome
:::
:::

## ::before и ::after

[[Псевдоэлемент]] пишут через два двоеточия. `::before` и `::after` добавляют в начало или конец элемента кусочек, которого нет в HTML. Текст задают свойством `content` — без него псевдоэлемент не появится.

:::shot img/css-pseudo.webp
Значок, стрелка у внешней ссылки и кавычки — ни одного лишнего тега в HTML
:::

:::sandbox Значок «Новинка» height=260
```html
<article class="card new">
  <h3>Раф с халвой</h3>
  <p>320 ₽</p>
</article>
```
```css
.card {
  position: relative;   /* от этого блока считается положение значка */
  max-width: 240px;
  padding: 18px;
  border: 1px solid #d1d9e0;
  border-radius: 10px;
}

.card.new::before {
  content: "Новинка";
  position: absolute;
  top: -10px;
  right: 12px;
  padding: 2px 8px;
  font-size: 12px;
  color: #fff;
  background: #1a7f37;
  border-radius: 999px;
}
```
:::

Уберите класс `new` у карточки — значок пропадёт. Строки с `position` пока примите как данность: позиционирование разберём в уроке {{n:layout}}.

Псевдоэлементы — для украшений. Важный текст пишите в HTML: программа экранного доступа может его не прочитать, а поиск не найдёт.

## Селекторы атрибутов

В квадратных скобках можно выбрать элемент по атрибуту:

| Селектор | Выбирает |
|---|---|
| `input[type="email"]` | Поля для почты |
| `a[target="_blank"]` | Ссылки, которые открываются в новой вкладке |
| `a[href^="tel:"]` | Ссылки, у которых адрес начинается с `tel:` |
| `img[alt=""]` | Картинки с пустым `alt` — декоративные |

```css
/* стрелка у всех ссылок, которые уводят на другой сайт */
a[target="_blank"]::after {
  content: " ↗";
}
```

## Цвета

| Запись | Пример | Когда |
|---|---|---|
| Имя | `tomato`, `white` | Опыты |
| HEX | `#1f883d` | Чаще всего: так цвета отдаёт дизайнер из Figma |
| RGB | `rgb(31 136 61)` | То же, что HEX, другими числами |
| С прозрачностью | `rgb(0 0 0 / 50%)` | Полупрозрачные подложки и тени |

```css
body {
  color: #1f2328;              /* цвет текста */
  background-color: #fffaf3;   /* цвет фона */
}
```

Помните про контраст из урока {{n:html-forms}}: серый текст на белом должен оставаться читаемым.

## Размеры и единицы

| Единица | Относительно чего | Где использовать |
|---|---|---|
| `px` | Пиксели экрана | Рамки, тени, мелкие детали |
| `rem` | Шрифт страницы, обычно 16px | Размер шрифта, отступы |
| `%` | Размер родителя | Ширина: `width: 50%` |
| `vw` / `vh` | Ширина / высота окна | Первый экран на всю высоту |

[[rem]] лучше `px` для текста: если человек увеличит шрифт в настройках браузера, страница увеличится вместе с ним.

## Текст и шрифты

:::sandbox Типографика height=340
```html
<article>
  <h1>Кофе, который хочется повторить</h1>
  <p>Обжариваем зерно сами каждую неделю. Варим эспрессо, фильтр и какао на овсяном молоке.</p>
</article>
```
```css
body {
  font-family: -apple-system, "Segoe UI", Roboto, sans-serif;
  font-size: 1rem;
  line-height: 1.5;
  color: #1f2328;
}

h1 {
  font-size: 2rem;
  font-weight: 700;
  line-height: 1.2;
}

article {
  max-width: 60ch;
}
```
:::

- `font-family` — список шрифтов: браузер берёт первый, который есть на компьютере. В конце всегда общий — `sans-serif`.
- `line-height: 1.5` — межстрочный интервал без единиц, в полтора раза больше шрифта. Для текста — от 1.4 до 1.6.
- `max-width: 60ch` — строка не шире 60 символов: такой текст легко читать.

## Подключаемые шрифты

Системный шрифт быстрый и выглядит аккуратно. Но у бренда часто свой характер, и его передаёт шрифт. Бесплатные шрифты с кириллицей есть на [Google Fonts](https://fonts.google.com).

:::shot img/css-fonts.webp
Одно название — четыре настроения. Шрифты с Google Fonts
:::

1. На fonts.google.com найдите шрифт. В фильтре Language выберите Cyrillic — останутся шрифты с русскими буквами.
2. **Get font** → **Get embed code**. Выберите нужные начертания, например 400 и 700.
3. Скопируйте теги `<link>` и вставьте в `<head>` перед своим `style.css`.
4. Укажите шрифт в CSS. Запасной шрифт после запятой нужен, пока основной загружается.

```html title="index.html"
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="css/style.css">
```

```css title="css/style.css"
h1, h2 {
  font-family: "Montserrat", sans-serif;
}
```

Хватит одного подключаемого шрифта для заголовков, основной текст — системным. Каждое начертание — ещё один файл, который скачивает посетитель.

## Оформление текста

:::shot img/css-text.webp
Самые частые свойства текста — на одной картинке
:::

| Свойство | Что делает | Пример |
|---|---|---|
| `font-weight` | Насыщенность от 100 до 900 | `font-weight: 700` — жирный |
| `font-style` | Курсив | `font-style: italic` |
| `text-transform` | Регистр букв | `uppercase` — все заглавные |
| `letter-spacing` | Расстояние между буквами | `0.1em` — для заглавных |
| `text-decoration` | Линия | `none` у ссылки, `line-through` у старой цены |
| `text-align` | Выравнивание строк | `center` для заголовка |
| `text-shadow` | Тень текста | `0 1px 2px rgb(0 0 0 / 40%)` |

Заглавные буквы в HTML не пишут: `Сезонное меню` в разметке, `text-transform: uppercase` в CSS. Так программа экранного доступа не прочитает текст по буквам.

## Фон, скругления и тени

:::shot img/css-effects.webp
Скругление и тень делают карточку «приподнятой» над страницей
:::

```css
.card {
  background-color: #fff;
  border-radius: 16px;                          /* скругление всех углов */
  box-shadow: 0 8px 24px rgb(31 35 40 / 18%);   /* сдвиг по x, по y, размытие, цвет */
}

.avatar {
  border-radius: 50%;                           /* квадрат превращается в круг */
}
```

У `box-shadow` четыре значения: сдвиг вправо, сдвиг вниз, размытие и цвет. Тень должна быть полупрозрачной и мягкой: чёрная жёсткая тень выглядит как ошибка вёрстки.

Фоном может быть и картинка:

```css
.hero {
  background-image: url("../img/hero.webp");   /* путь — от файла CSS */
  background-size: cover;                        /* заполнить блок, лишнее обрезать */
  background-position: center;
}
```

## Градиенты

Градиент — плавный переход цветов. Для CSS это картинка, поэтому пишется в `background`.

:::shot img/css-gradients.webp
Слева направо: вертикальный, диагональный, затемнение поверх фото — чтобы белый текст читался
:::

:::sandbox Градиент height=260
```html
<section class="hero">Кофе, который хочется повторить</section>
```
```css
.hero {
  display: grid;
  place-items: center;
  height: 200px;
  font-size: 24px;
  font-weight: 700;
  color: #fff;
  border-radius: 14px;
  background: linear-gradient(135deg, #bc4c00, #fb8f44);
}
```
:::

Поменяйте `135deg` на `to right`, добавьте третий цвет через запятую. Градиенты хороши для кнопок и первого экрана, но в меру: цвета должны быть из палитры сайта.

## Каскад и специфичность

Бывает, что несколько правил задают одно и то же свойство одному элементу. Какое победит, решает [[каскад]]. Главное в нём — [[специфичность]]: вес селектора.

:::diagram id=specificity
type: flow
caption: "Слева направо вес растёт. Более весомый селектор побеждает, где бы ни стоял"
items:
  - {title: "`p`", text: "тег — самый лёгкий", kind: muted, icon: false}
  - {arrow: right}
  - {title: "`.note`", text: "класс, :hover — тяжелее любого числа тегов", kind: front, icon: false}
  - {arrow: right}
  - {title: "`#promo`", text: "id — тяжелее любого числа классов", kind: accent, icon: false}
  - {arrow: right}
  - {title: "`style=\"…\"`", text: "атрибут в HTML — тяжелее всех", kind: db, icon: false}
:::

Если вес равный, побеждает правило, которое стоит ниже в файле.

:::sandbox Кто победит? height=300
```html
<p class="note" id="promo">Какого я цвета?</p>
```
```css
#promo {
  color: purple;
}

.note {
  color: green;
}

p {
  color: red;
}
```
:::

Текст фиолетовый: у `#promo` самый большой вес. Удалите правило `#promo` — станет зелёным. Теперь поменяйте местами `.note` и `p` — всё равно зелёный: класс весомее тега, порядок не важен.

:::mistake !important
`color: red !important;` перебивает всё. Одно `!important` тянет за собой следующее, и через месяц стили никто не понимает. Вместо этого сделайте селектор точнее или используйте класс.
:::

## Наследование

Часть свойств [[наследование|наследуется]]: задали цвет и шрифт у `body` — их получил весь текст внутри. Рамки, отступы и фон не наследуются.

| Наследуются | Не наследуются |
|---|---|
| `color`, `font-family`, `font-size`, `line-height`, `text-align` | `margin`, `padding`, `border`, `background`, `width` |

Поэтому шрифт и цвет текста задают один раз на `body`, а не на каждом абзаце.

## Блочная модель

Каждый элемент на странице — прямоугольник из четырёх слоёв. Это [[блочная модель]]. В DevTools на вкладке Computed вы увидите такую же схему в тех же цветах.

:::diagram id=box-model
type: flow
caption: "Слои элемента от внешнего к внутреннему. Цвета — как в DevTools"
items:
  - group: "margin — внешний отступ, прозрачный"
    kind: db
    icon: false
    items:
      - group: "border — рамка"
        kind: muted
        icon: false
        items:
          - group: "padding — внутренний отступ, фон виден"
            kind: back
            icon: false
            items:
              - {title: "content — содержимое", text: "width и height", kind: front, icon: false}
:::

```css
.card {
  width: 300px;
  padding: 24px;              /* внутри: от рамки до текста */
  border: 1px solid #d1d9e0;  /* толщина, стиль, цвет */
  margin: 16px auto;          /* снаружи: сверху-снизу 16px, по бокам auto — по центру */
}
```

Сюрприз: ширина такой карточки не 300, а 350 пикселей — браузер прибавляет padding и border к `width`. Это чинит одна строка, которую пишут в начале каждого проекта:

```css
*,
*::before,
*::after {
  box-sizing: border-box;   /* width — это вся коробка, включая padding и border */
}
```

:::sandbox box-sizing height=330
```html
<div class="box content-box">content-box: 200 + 40 + 40 + 4 + 4 = 288px</div>
<div class="box border-box">border-box: ровно 200px</div>
```

## Если не влезает: overflow

Если у блока задана высота, а текста больше, он вылезет наружу. Что делать с лишним, решает `overflow`.

:::shot img/css-overflow.webp
Один текст в блоке высотой 64px
:::

| Значение | Что происходит | Когда |
|---|---|---|
| `visible` | Содержимое вылезает, по умолчанию | Почти всегда: высоту лучше не задавать |
| `hidden` | Лишнее обрезается | Картинка в скруглённой карточке |
| `auto` | Появляется прокрутка, если нужно | Длинная таблица или код на телефоне |

```css
.table-wrap {
  overflow-x: auto;   /* таблица прокручивается сама, страница — нет */
}
```

## Стили в DevTools

DevTools (<kbd>⌥</kbd>+<kbd>⌘</kbd>+<kbd>I</kbd>) — лучший способ понять, почему элемент выглядит так, а не иначе.

1. Правый клик по элементу → **Просмотреть код**. Элемент выделится во вкладке Elements.
2. Справа панель **Styles** — все правила, которые к нему относятся. Сверху — самые важные.
3. **Зачёркнутое** объявление проиграло в каскаде: его перебило правило выше.
4. Щёлкните по значению и поменяйте его — страница обновится сразу. Галочка слева отключает объявление.
5. Вкладка **Computed** — итоговые значения и схема блочной модели.

| Что видно в Styles | Что это значит |
|---|---|
| `element.style { }` | Стили из атрибута `style`. Сюда же можно дописать свойство для опыта |
| `.note { … }` и справа `style.css:12` | Правило и место в файле. Щелчок по `style.css:12` откроет файл на этой строке |
| ~~`color: red`~~ | Объявление проиграло в каскаде |
| Значок ⚠ у свойства | Ошибка в названии или значении: браузер его не понял |
| Цветной квадратик у цвета | Палитра и пипетка: можно взять цвет с любого места страницы |
| Кнопка `:hov` | Включить `:hover`, `:focus` и другие состояния без мыши |

:::shot img/css-devtools-styles.webp width=640
Новое свойство, дописанное прямо в Styles, сразу видно на странице. Картинка из документации Chrome
:::

:::tip Правки в DevTools не сохраняются
Нашли нужное значение в DevTools — перенесите его в `style.css`. После обновления страницы изменения в DevTools пропадут.
:::

## Частые ошибки

:::mistake Стили не применились
Проверьте по порядку: подключён ли файл (путь в `href`) и сохранён ли он. Потом — нет ли опечатки в селекторе: точку у класса забывают чаще всего. И закрыты ли все фигурные скобки.
:::

:::mistake Карточка вылезла за край
Ширина 100% плюс padding больше родителя. Добавьте `box-sizing: border-box` для всех элементов.
:::

:::mistake Стили по id
`#header { … }` весит больше сотни классов — потом его не перебить. Стилизуйте классами.
:::

## Квиз

:::quiz
- q: Где правильно подключать стили для сайта?
  options:
    - Атрибутом style у каждого элемента
    - Отдельным файлом через `<link rel="stylesheet">` в head
    - Тегом `<style>` внизу body
    - В JavaScript
  answer: 1
  why: Один файл на сайт легко найти, поменять и переиспользовать на всех страницах.
- q: Что выберет селектор `nav a`?
  options:
    - Все ссылки и все nav
    - Ссылки внутри nav
    - Элемент с классом «nav a»
    - Только первую ссылку в nav
  answer: 1
  why: Пробел означает «внутри». Запятая — «и то, и другое».
- q: Как в CSS выбрать элементы с `class="card"`?
  options:
    - "`card`"
    - "`.card`"
    - "`#card`"
    - '`[card]`'
  answer: 1
  why: Точка — класс, решётка — id. Без символа — имя тега.
- q: '`p { color: red; }` стоит ниже, чем `.note { color: green; }`. Какого цвета `<p class="note">`?'
  options:
    - Красного — правило ниже
    - Зелёного — класс весомее тега
    - Чёрного
    - Смешается в коричневый
  answer: 1
  why: Порядок решает только при равной специфичности. Класс всегда весомее тега.
- q: Какие свойства наследуются от родителя?
  options:
    - margin и padding
    - color и font-family
    - border и background
    - width и height
  answer: 1
  why: Текстовые свойства наследуются, поэтому шрифт и цвет задают один раз на body.
- q: '`width: 300px; padding: 24px; border: 1px solid;` без box-sizing. Какая получится ширина?'
  options:
    - "300px"
    - "324px"
    - "350px"
    - "348px"
  answer: 2
  why: "300 + 24 × 2 + 1 × 2 = 350. С `box-sizing: border-box` было бы ровно 300."
- q: 'Как выбрать каждую вторую строку таблицы, чтобы сделать «зебру»?'
  options:
    - "`tr:second`"
    - "`tr:nth-child(even)`"
    - "`tr + tr`"
    - "`tr:last-child`"
  answer: 1
  why: 'nth-child(even) — чётные элементы среди соседей, odd — нечётные.'
- q: 'Что обязательно нужно для `::before`, чтобы он появился?'
  options:
    - Тег before в HTML
    - Свойство content, хотя бы пустая строка
    - Класс before у элемента
    - position absolute
  answer: 1
  why: 'Без content псевдоэлемент не создаётся. Даже для пустого украшения пишут `content: ""`.'
- q: Для чего лучше единица rem?
  options:
    - Для толщины рамки
    - Для размера шрифта и отступов
    - Для ширины в процентах от родителя
    - Ни для чего — это устаревшая единица
  answer: 1
  why: rem растёт вместе с настройкой шрифта в браузере. Рамки обычно задают в px.
- q: В DevTools объявление зачёркнуто. Что это значит?
  options:
    - В нём синтаксическая ошибка
    - Его перебило другое правило
    - Браузер не поддерживает свойство
    - Оно применится после обновления
  answer: 1
  why: Зачёркнутое проиграло в каскаде. Если свойство с ошибкой, DevTools покажет рядом значок предупреждения.
:::
