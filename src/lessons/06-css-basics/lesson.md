## Подключить CSS

[[CSS]] описывает внешний вид. Стили кладут в отдельный файл и подключают в `<head>`:

```html title="index.html"
<head>
  <meta charset="utf-8">
  <title>Кофейня «Зерно»</title>
  <link rel="stylesheet" href="css/style.css">
</head>
```

:::diagram id=css-files
type: tree
caption: "Стили в папке css, путь в href — от HTML-файла"
items:
  - name: zerno
    items:
      - {name: index.html, note: "`<link rel=\"stylesheet\" href=\"css/style.css\">`"}
      - name: css
        items:
          - {name: style.css, mark: true, note: все стили сайта}
:::

| Способ | Когда |
|---|---|
| Файл и `<link>` | Всегда. Один файл стилей на весь сайт |
| Тег `<style>` в `<head>` | Быстрые опыты, одна страница-пример |
| Атрибут `style="…"` | Почти никогда: такие стили трудно найти и переопределить |

## Анатомия правила

Правило CSS состоит из [[селектор|селектора]] — к чему применить — и блока объявлений в фигурных скобках.

:::diagram id=rule-anatomy
type: flow
caption: "Одно правило: все заголовки h1 — коричневые и размером 2rem"
items:
  - {title: "`h1`", text: "селектор: к каким элементам", kind: accent, icon: false}
  - {title: "`color: brown;`", text: "свойство и значение через двоеточие, в конце точка с запятой", kind: back, icon: false}
  - {title: "`font-size: 2rem;`", text: "ещё одно объявление", kind: back, icon: false}
:::

```css title="css/style.css"
h1 {
  color: brown;
  font-size: 2rem;
}
```

:::sandbox Первые правила height=300
```html
<h1>Кофейня «Зерно»</h1>
<p>Варим кофе с 8 утра.</p>
```
```css
h1 {
  color: brown;
  font-size: 2rem;
}

p {
  color: #59636e;
  font-size: 18px;
}
```
:::

Поменяйте `brown` на `tomato`, `18px` на `24px`. Удалите точку с запятой после `brown` — сломается следующее объявление. Так выглядит самая частая ошибка в CSS.

## Селекторы

[[Селектор]] выбирает элементы. Чаще всего вы будете писать классы: атрибут `class` в HTML и точка в CSS.

| Селектор | Выбирает | Пример |
|---|---|---|
| `p` | Все теги p | `p { line-height: 1.5; }` |
| `.card` | Все элементы с классом card | `<div class="card">` |
| `nav a` | Ссылки внутри nav — через пробел | только меню, не весь сайт |
| `h1, h2` | И то и другое — через запятую | общий шрифт заголовков |
| `a:hover` | Ссылку под курсором мыши | подчёркивание при наведении |
| `a:focus-visible` | Элемент в фокусе после Tab | рамка для клавиатуры |
| `#logo` | Элемент с id="logo" | для стилей лучше класс |

:::sandbox Классы и состояния height=320
```html
<nav>
  <a href="#">Меню</a>
  <a href="#">О нас</a>
</nav>
<article class="card">
  <h2 class="card-title">Капучино</h2>
  <p>220 ₽</p>
</article>
```
```css
nav a {
  margin-right: 12px;
  color: #0969da;
}

nav a:hover {
  text-decoration: none;
}

.card {
  padding: 16px;
  border: 1px solid #d1d9e0;
  border-radius: 8px;
}

.card-title {
  margin: 0 0 8px;
}
```
:::

Имена классов — по смыслу, латиницей, через дефис: `.card`, `.card-title`, `.main-nav`. Не по виду: `.red-text` устареет, как только цвет поменяют.

## Цвета

| Запись | Пример | Когда |
|---|---|---|
| Имя | `tomato`, `white` | Опыты |
| HEX | `#1f883d` | Чаще всего: так цвета отдаёт дизайнер из Figma |
| RGB | `rgb(31 136 61)` | То же, что HEX, другими числами |
| С прозрачностью | `rgb(0 0 0 / 50%)` | Полупрозрачные подложки и тени |

```css
body {
  color: #1f2328;              /* цвет текста */
  background-color: #fffaf3;   /* цвет фона */
}
```

Помните про контраст из урока {{n:html-forms}}: серый текст на белом должен оставаться читаемым.

## Размеры и единицы

| Единица | Относительно чего | Где использовать |
|---|---|---|
| `px` | Пиксели экрана | Рамки, тени, мелкие детали |
| `rem` | Шрифт страницы, обычно 16px | Размер шрифта, отступы |
| `%` | Размер родителя | Ширина: `width: 50%` |
| `vw` / `vh` | Ширина / высота окна | Первый экран на всю высоту |

[[rem]] лучше `px` для текста: если человек увеличит шрифт в настройках браузера, страница увеличится вместе с ним.

## Текст и шрифты

:::sandbox Типографика height=340
```html
<article>
  <h1>Кофе, который хочется повторить</h1>
  <p>Обжариваем зерно сами каждую неделю. Варим эспрессо, фильтр и какао на овсяном молоке.</p>
</article>
```
```css
body {
  font-family: -apple-system, "Segoe UI", Roboto, sans-serif;
  font-size: 1rem;
  line-height: 1.5;
  color: #1f2328;
}

h1 {
  font-size: 2rem;
  font-weight: 700;
  line-height: 1.2;
}

article {
  max-width: 60ch;
}
```
:::

- `font-family` — список шрифтов: браузер берёт первый, который есть на компьютере. В конце всегда общий — `sans-serif`.
- `line-height: 1.5` — межстрочный интервал без единиц, в полтора раза больше шрифта. Для текста — от 1.4 до 1.6.
- `max-width: 60ch` — строка не шире 60 символов: такой текст легко читать.

## Каскад и специфичность

Бывает, что несколько правил задают одно и то же свойство одному элементу. Какое победит, решает [[каскад]]. Главное в нём — [[специфичность]]: вес селектора.

:::diagram id=specificity
type: flow
caption: "Слева направо вес растёт. Более весомый селектор побеждает, где бы ни стоял"
items:
  - {title: "`p`", text: "тег — самый лёгкий", kind: muted, icon: false}
  - {arrow: right}
  - {title: "`.note`", text: "класс, :hover — тяжелее любого числа тегов", kind: front, icon: false}
  - {arrow: right}
  - {title: "`#promo`", text: "id — тяжелее любого числа классов", kind: accent, icon: false}
  - {arrow: right}
  - {title: "`style=\"…\"`", text: "атрибут в HTML — тяжелее всех", kind: db, icon: false}
:::

Если вес равный, побеждает правило, которое стоит ниже в файле.

:::sandbox Кто победит? height=300
```html
<p class="note" id="promo">Какого я цвета?</p>
```
```css
#promo {
  color: purple;
}

.note {
  color: green;
}

p {
  color: red;
}
```
:::

Текст фиолетовый: у `#promo` самый большой вес. Удалите правило `#promo` — станет зелёным. Теперь поменяйте местами `.note` и `p` — всё равно зелёный: класс весомее тега, порядок не важен.

:::mistake !important
`color: red !important;` перебивает всё. Одно `!important` тянет за собой следующее, и через месяц стили никто не понимает. Вместо этого сделайте селектор точнее или используйте класс.
:::

## Наследование

Часть свойств [[наследование|наследуется]]: задали цвет и шрифт у `body` — их получил весь текст внутри. Рамки, отступы и фон не наследуются.

| Наследуются | Не наследуются |
|---|---|
| `color`, `font-family`, `font-size`, `line-height`, `text-align` | `margin`, `padding`, `border`, `background`, `width` |

Поэтому шрифт и цвет текста задают один раз на `body`, а не на каждом абзаце.

## Блочная модель

Каждый элемент на странице — прямоугольник из четырёх слоёв. Это [[блочная модель]]. В DevTools на вкладке Computed вы увидите такую же схему в тех же цветах.

:::diagram id=box-model
type: flow
caption: "Слои элемента от внешнего к внутреннему. Цвета — как в DevTools"
items:
  - group: "margin — внешний отступ, прозрачный"
    kind: db
    icon: false
    items:
      - group: "border — рамка"
        kind: muted
        icon: false
        items:
          - group: "padding — внутренний отступ, фон виден"
            kind: back
            icon: false
            items:
              - {title: "content — содержимое", text: "width и height", kind: front, icon: false}
:::

```css
.card {
  width: 300px;
  padding: 24px;              /* внутри: от рамки до текста */
  border: 1px solid #d1d9e0;  /* толщина, стиль, цвет */
  margin: 16px auto;          /* снаружи: сверху-снизу 16px, по бокам auto — по центру */
}
```

Сюрприз: ширина такой карточки не 300, а 350 пикселей — браузер прибавляет padding и border к `width`. Это чинит одна строка, которую пишут в начале каждого проекта:

```css
*,
*::before,
*::after {
  box-sizing: border-box;   /* width — это вся коробка, включая padding и border */
}
```

:::sandbox box-sizing height=330
```html
<div class="box content-box">content-box: 200 + 40 + 40 + 4 + 4 = 288px</div>
<div class="box border-box">border-box: ровно 200px</div>
```
```css
.box {
  width: 200px;
  padding: 40px;
  border: 4px solid #1f883d;
  margin-bottom: 12px;
  background: #dafbe1;
}

.content-box { box-sizing: content-box; }
.border-box { box-sizing: border-box; }
```
:::

## Стили в DevTools

DevTools (<kbd>⌥</kbd>+<kbd>⌘</kbd>+<kbd>I</kbd>) — лучший способ понять, почему элемент выглядит так, а не иначе.

1. Правый клик по элементу → **Просмотреть код**. Элемент выделится во вкладке Elements.
2. Справа панель **Styles** — все правила, которые к нему относятся. Сверху — самые важные.
3. **Зачёркнутое** объявление проиграло в каскаде: его перебило правило выше.
4. Щёлкните по значению и поменяйте его — страница обновится сразу. Галочка слева отключает объявление.
5. Вкладка **Computed** — итоговые значения и схема блочной модели.

| Что видно в Styles | Что это значит |
|---|---|
| `element.style { }` | Стили из атрибута `style`. Сюда же можно дописать свойство для опыта |
| `.note { … }` и справа `style.css:12` | Правило и место в файле. Щелчок по `style.css:12` откроет файл на этой строке |
| ~~`color: red`~~ | Объявление проиграло в каскаде |
| Значок ⚠ у свойства | Ошибка в названии или значении: браузер его не понял |
| Цветной квадратик у цвета | Палитра и пипетка: можно взять цвет с любого места страницы |

:::tip Правки в DevTools не сохраняются
Нашли нужное значение в DevTools — перенесите его в `style.css`. После обновления страницы изменения в DevTools пропадут.
:::

## Частые ошибки

:::mistake Стили не применились
Проверьте по порядку: подключён ли файл (путь в `href`) и сохранён ли он. Потом — нет ли опечатки в селекторе: точку у класса забывают чаще всего. И закрыты ли все фигурные скобки.
:::

:::mistake Карточка вылезла за край
Ширина 100% плюс padding больше родителя. Добавьте `box-sizing: border-box` для всех элементов.
:::

:::mistake Стили по id
`#header { … }` весит больше сотни классов — потом его не перебить. Стилизуйте классами.
:::

## Квиз

:::quiz
- q: Где правильно подключать стили для сайта?
  options:
    - Атрибутом style у каждого элемента
    - Отдельным файлом через `<link rel="stylesheet">` в head
    - Тегом `<style>` внизу body
    - В JavaScript
  answer: 1
  why: Один файл на сайт легко найти, поменять и переиспользовать на всех страницах.
- q: Что выберет селектор `nav a`?
  options:
    - Все ссылки и все nav
    - Ссылки внутри nav
    - Элемент с классом «nav a»
    - Только первую ссылку в nav
  answer: 1
  why: Пробел означает «внутри». Запятая — «и то, и другое».
- q: Как в CSS выбрать элементы с `class="card"`?
  options:
    - "`card`"
    - "`.card`"
    - "`#card`"
    - '`[card]`'
  answer: 1
  why: Точка — класс, решётка — id. Без символа — имя тега.
- q: '`p { color: red; }` стоит ниже, чем `.note { color: green; }`. Какого цвета `<p class="note">`?'
  options:
    - Красного — правило ниже
    - Зелёного — класс весомее тега
    - Чёрного
    - Смешается в коричневый
  answer: 1
  why: Порядок решает только при равной специфичности. Класс всегда весомее тега.
- q: Какие свойства наследуются от родителя?
  options:
    - margin и padding
    - color и font-family
    - border и background
    - width и height
  answer: 1
  why: Текстовые свойства наследуются, поэтому шрифт и цвет задают один раз на body.
- q: '`width: 300px; padding: 24px; border: 1px solid;` без box-sizing. Какая получится ширина?'
  options:
    - "300px"
    - "324px"
    - "350px"
    - "348px"
  answer: 2
  why: "300 + 24 × 2 + 1 × 2 = 350. С `box-sizing: border-box` было бы ровно 300."
- q: Для чего лучше единица rem?
  options:
    - Для толщины рамки
    - Для размера шрифта и отступов
    - Для ширины в процентах от родителя
    - Ни для чего — это устаревшая единица
  answer: 1
  why: rem растёт вместе с настройкой шрифта в браузере. Рамки обычно задают в px.
- q: В DevTools объявление зачёркнуто. Что это значит?
  options:
    - В нём синтаксическая ошибка
    - Его перебило другое правило
    - Браузер не поддерживает свойство
    - Оно применится после обновления
  answer: 1
  why: Зачёркнутое проиграло в каскаде. Если свойство с ошибкой, DevTools покажет рядом значок предупреждения.
:::
