## Воркшоп: оформляем страницу кофейни (20 мин)

**На слайде:** шесть шагов: от подключения стилей до переноса правок из DevTools в файл.

**Подготовить заранее:** папка `workshop-html` открыта в VS Code, Go Live включён, `index.html` в браузере. Окна VS Code и Chrome стоят рядом.

**Показать вживую:**
1. **Подключить.** В проводнике New Folder → `css` → New File → `style.css`.
   - В `head` страницы наберите `link:css` → <kbd>Tab</kbd>, поправьте путь на `css/style.css`.
   - В `style.css`: `body { background: pink; }` → <kbd>⌘</kbd>+<kbd>S</kbd>. Розовый фон — файл подключён. Удалите эту строку.
2. **Текст.**
   - `body { font-family: -apple-system, "Segoe UI", sans-serif; line-height: 1.5; color: #1f2328; }`.
   - `main { max-width: 720px; margin: 0 auto; padding: 0 16px; }` — текст по центру и не шире 60–70 символов.
   - Сузьте окно браузера — поля `padding` не дают тексту прилипнуть к краю.
3. **Карточка.** В HTML оберните список напитков в `section.card` (выделить строки → <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>P</kbd> → Emmet: Wrap with Abbreviation → `section.card`).
   - В CSS: `.card { padding: 24px; border: 1px solid #d1d9e0; border-radius: 12px; }`.
   - `.card h2 { margin-top: 0; }` — селектор потомка.
4. **DevTools → Styles.** Правый щелчок по карточке → «Просмотреть код».
   - Справа панель Styles: все правила этой карточки. Щёлкните по `24px` → стрелки <kbd>↑</kbd> <kbd>↓</kbd> меняют на 1, с <kbd>⇧</kbd> — на 10.
   - Щёлкните по цветному квадратику у `#d1d9e0` — палитра. Пипеткой возьмите цвет с кнопки или логотипа.
   - Снимите галочку у свойства — оно выключилось. Поставьте обратно.
   - Щёлкните по пустому месту внутри правила `.card` — добавьте `background: #fffaf3`.
5. **Каскад.** В CSS добавьте `section { border-color: red; }` — рамка не покраснела.
   - В Styles правило `section` зачёркнуто: у `.card` вес больше. Поменяйте на `section.card` ниже по файлу — теперь красная.
   - Вкладка Computed: схема блочной модели. Наведите на слои — они подсвечиваются на странице.
   - Добавьте `.card { width: 300px; }` — в Computed ширина 350 с отступами и рамкой. Добавьте в начало файла `*, *::before, *::after { box-sizing: border-box; }` — стало 300.
6. **Обратно в файл.** Правки в DevTools живут до обновления: <kbd>⌘</kbd>+<kbd>R</kbd> — фон карточки пропал.
   - Повторите правку, правый щелчок по свойству → Copy declaration → вставьте в `style.css` → <kbd>⌘</kbd>+<kbd>S</kbd>.

**Рассказать:** рабочий цикл фронтендера — подобрать значение в DevTools, перенести в файл. «Стиль не работает» — сначала смотрим в Styles, зачёркнут ли он и кем.
