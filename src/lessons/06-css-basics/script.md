Что открыть заранее: слайды, текст урока (песочницы «Зебра и последний пункт», «Значок „Новинка“», «Кто победит?», «Градиент», «box-sizing»), VS Code с домашкой, Chrome с DevTools, fonts.google.com во вкладке.

Цель занятия: ученик подключает CSS, пишет правила с классами и псевдоклассами, объясняет, почему победило одно из правил, оформляет текст, фон и тени и находит стили элемента в DevTools.

## Титульный слайд (1 мин)

**На слайде:** название урока.

**Рассказать:** сегодня страницы из прошлых уроков станут красивыми — и научимся понимать, почему стиль сработал или нет.

## Воркшоп: оформляем страницу кофейни (16 мин)

**На слайде:** четыре шага: подключить, текст, карточка, DevTools.

**Подготовить заранее:** папка `workshop-html` открыта в VS Code, Go Live включён, `index.html` в браузере. Окна VS Code и Chrome стоят рядом. Вкладка fonts.google.com.

**Показать вживую:**
1. **Подключить.** В проводнике New Folder → `css` → New File → `style.css`.
   - В `head` страницы наберите `link:css` → <kbd>Tab</kbd>, поправьте путь на `css/style.css`.
   - В `style.css`: `body { background: pink; }` → <kbd>⌘</kbd>+<kbd>S</kbd>. Розовый фон — файл подключён. Удалите эту строку.
2. **Текст и шрифт.**
   - `body { font-family: -apple-system, "Segoe UI", sans-serif; line-height: 1.5; color: #1f2328; }`.
   - `main { max-width: 720px; margin: 0 auto; padding: 0 16px; }` — текст по центру и не шире 60–70 символов.
   - Google Fonts → фильтр Cyrillic → Montserrat → Get font → Get embed code → скопируйте `<link>` в `head` перед `style.css`. В CSS: `h1, h2 { font-family: "Montserrat", sans-serif; }`.
3. **Карточка.** В HTML оберните список напитков в `section.card` (выделить строки → <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>P</kbd> → Emmet: Wrap with Abbreviation → `section.card`).
   - В CSS: `.card { padding: 24px; border: 1px solid #d1d9e0; border-radius: 12px; box-shadow: 0 8px 24px rgb(31 35 40 / 12%); }`.
   - `.card h2 { margin-top: 0; }` — селектор потомка. `.card li:nth-child(even) { background: #f6f8fa; }` — зебра.
   - Ссылкам в меню: `nav a:hover { color: #bc4c00; }` и `nav a:focus-visible { outline: 3px solid #0969da; }`. Пройдитесь <kbd>Tab</kbd> по странице.
4. **DevTools → Styles.** Правый щелчок по карточке → «Просмотреть код».
   - Справа панель Styles: все правила этой карточки. Щёлкните по `24px` → стрелки <kbd>↑</kbd> <kbd>↓</kbd> меняют на 1, с <kbd>⇧</kbd> — на 10.
   - Щёлкните по цветному квадратику у `#d1d9e0` — палитра. Пипеткой возьмите цвет с кнопки или логотипа.
   - Кнопка `:hov` → галочка `:hover` у ссылки меню — видно стиль наведения без мыши.
5. **Каскад.** В CSS добавьте `section { border-color: red; }` — рамка не покраснела.
   - В Styles правило `section` зачёркнуто: у `.card` вес больше. Поменяйте на `section.card` ниже по файлу — теперь красная.
   - Вкладка Computed: схема блочной модели. Добавьте `.card { width: 300px; }` — ширина 350. Добавьте в начало файла `*, *::before, *::after { box-sizing: border-box; }` — стало 300.
6. **Обратно в файл.** Правки в DevTools живут до обновления: <kbd>⌘</kbd>+<kbd>R</kbd> — изменения пропали.
   - Повторите правку, правый щелчок по свойству → Copy declaration → вставьте в `style.css` → <kbd>⌘</kbd>+<kbd>S</kbd>.

**Рассказать:** рабочий цикл фронтендера — подобрать значение в DevTools, перенести в файл. «Стиль не работает» — сначала смотрим в Styles, зачёркнут ли он и кем.
