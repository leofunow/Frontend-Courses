HTML говорит браузеру, что есть на странице. Как это выглядит — задача CSS

---

## Разметка

:::cols
```html
<h1>Кофейня «Зерно»</h1>
<p>Варим кофе с 8 утра.</p>
<ul>
  <li>Эспрессо</li>
  <li>Капучино</li>
</ul>
```
+++
- `h1` — главный заголовок
- `p` — абзац
- `ul` + `li` — список
:::

---

## Анатомия тега

:::use tag-anatomy

Одиночные теги без содержимого: `img`, `br`, `meta`, `link`, `input`

---

## Вложенность как коробки

:::cols
**Правильно**

```html
<p>Кофе <strong>очень</strong> горячий</p>
```
+++
**Неправильно**

```html
<p>Кофе <strong>очень</p> горячий</strong>
```
:::

## Заголовки и текст

| Тег | Смысл |
|---|---|
| `h1` | Главный заголовок, один на страницу |
| `h2`–`h6` | Разделы и подразделы |
| `p` | Абзац |
| `strong` / `em` | Важное / ударение |

Уровень заголовка — по смыслу, не по размеру

---

## Списки

:::cols
```html
<ul>
  <li>Молоко</li>
  <li>Яйца</li>
</ul>
```
+++
```html
<ol>
  <li>Смешайте</li>
  <li>Жарьте</li>
</ol>
```
:::

`ul` — порядок не важен, `ol` — важен

## Ссылки

## Картинки

```html
<img src="img/pancakes.jpg" alt="Стопка блинов со сметаной">
```

- `alt` — что на картинке, для тех, кто её не видит
- Имена файлов — строчными латинскими: на сервере `Logo.PNG` ≠ `logo.png`

## Какой тег выбрать

| Кусок страницы | Тег |
|---|---|
| Шапка | `header` |
| Меню | `nav` |
| Основное | `main` |
| Статья, карточка | `article` |
| Боковая колонка | `aside` |
| Подвал | `footer` |
| Просто обёртка | `div` |
