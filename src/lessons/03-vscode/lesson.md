## Интерфейс

VS Code — [[редактор кода]], в котором вы проведёте весь курс. Окно делится на четыре зоны.

:::shot img/vscode-ui.webp
Интерфейс VS Code: открыт HTML-файл
:::

1. **Панель действий** — переключает боковую панель: файлы, поиск, Git, расширения.
2. **Боковая панель** — сейчас в ней проводник (Explorer) с файлами проекта.
3. **Редактор** — здесь пишете код. Каждый открытый файл — отдельная вкладка.
4. **Строка состояния** — язык файла, номер строки, ошибки. Справа появится кнопка Live Server.

Снизу по <kbd>⌃</kbd>+<kbd>`</kbd> открывается ещё одна зона — встроенный терминал. О нём ниже.

:::note Язык интерфейса
На скриншотах VS Code на английском, как у большинства разработчиков: статьи и ответы на форумах тоже на английском. Если хочется русский — поставьте расширение Russian Language Pack, названия пунктов меню станут другими.
:::

## Открыть папку проекта

Проект — это папка с файлами. Открывайте в VS Code всегда **папку**, а не отдельный файл: тогда работают проводник, поиск по проекту, терминал в нужной папке и Live Server.

:::shot img/vscode-welcome.webp width=640
Кнопка Open Folder на пустом окне
:::

Три способа открыть папку:

- кнопка **Open Folder** на стартовом экране или меню **File → Open Folder…** (<kbd>⌘</kbd>+<kbd>O</kbd>);
- перетащить папку из Finder на значок VS Code в Dock;
- в Терминале перейти в папку и набрать `code .`

:::tip Вопрос про доверие
При первом открытии папки VS Code спросит, доверяете ли вы авторам файлов (Do you trust the authors…). Для своих учебных папок отвечайте **Yes, I trust the authors**.
:::

## Файлы и папки в проводнике

Проводник показывает папку проекта деревом. Кнопки создания появляются, если навести мышь на название проекта в проводнике.

:::diagram id=project-tree
type: tree
caption: Типичный учебный проект в проводнике VS Code
items:
  - name: hello
    note: открытая папка проекта
    items:
      - name: css
        items:
          - {name: style.css}
      - {name: index.html, mark: true, note: открыт в редакторе}
      - {name: about.html}
:::

| Действие | Как сделать |
|---|---|
| Новый файл | Значок с плюсом у названия проекта, затем имя с расширением: `index.html` |
| Новая папка | Значок папки с плюсом рядом |
| Переименовать | Выделить файл и нажать <kbd>Return</kbd> |
| Удалить в Корзину | Выделить и нажать <kbd>⌘</kbd>+<kbd>⌫</kbd> |
| Файл в подпапке | Написать имя через слеш: `css/style.css` — папка создастся сама |

## Палитра команд и быстрый переход

Две клавиши заменяют почти всё меню:

- <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>P</kbd> — **[[палитра команд]]**. Начните вводить название действия, VS Code найдёт его. Справа от команды — её сочетание клавиш.
- <kbd>⌘</kbd>+<kbd>P</kbd> — **быстрый переход к файлу**. Наберите часть имени — `ind` найдёт `index.html`.

:::shot img/vscode-palette.webp width=640
Палитра команд: команда Format Document и её сочетание ⇧⌥F
:::

Не помните, как что-то сделать — ищите в палитре. Со временем сочетания запомнятся сами.

## Горячие клавиши редактора

Десять [[горячие клавиши|сочетаний]], которые окупаются уже в первую неделю:

| Сочетание | Что делает |
|---|---|
| <kbd>⌘</kbd>+<kbd>S</kbd> | Сохранить файл. Несохранённый файл отмечен точкой ● на вкладке |
| <kbd>⌘</kbd>+<kbd>Z</kbd> / <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>Z</kbd> | Отменить / вернуть |
| <kbd>⌘</kbd>+<kbd>/</kbd> | Закомментировать строку или выделение |
| <kbd>⌥</kbd>+<kbd>↑</kbd> / <kbd>⌥</kbd>+<kbd>↓</kbd> | Переместить строку вверх / вниз |
| <kbd>⇧</kbd>+<kbd>⌥</kbd>+<kbd>↓</kbd> | Продублировать строку |
| <kbd>⌘</kbd>+<kbd>D</kbd> | Выделить следующее такое же слово — несколько курсоров |
| <kbd>⌥</kbd>+щелчок | Поставить ещё один курсор |
| <kbd>⌘</kbd>+<kbd>X</kbd> без выделения | Вырезать всю строку |
| <kbd>⌘</kbd>+<kbd>F</kbd> / <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>F</kbd> | Найти в файле / во всём проекте |
| <kbd>⌘</kbd>+<kbd>B</kbd> | Спрятать и показать боковую панель |

Самое полезное — несколько курсоров. Выделите слово `item`, нажмите <kbd>⌘</kbd>+<kbd>D</kbd> три раза и напечатайте `card` — поменяются все четыре:

:::cols
**До**

```html
<li class="item">Кофе</li>
<li class="item">Чай</li>
<li class="item">Какао</li>
<li class="item">Сок</li>
```
+++
**После ⌘D ⌘D ⌘D и ввода card**

```html
<li class="card">Кофе</li>
<li class="card">Чай</li>
<li class="card">Какао</li>
<li class="card">Сок</li>
```
:::

## Emmet: HTML сокращениями

[[Emmet]] встроен в VS Code. Пишете сокращение, нажимаете <kbd>Tab</kbd> — получаете готовый HTML. Самое частое — `!` в пустом HTML-файле: каркас страницы.

:::shot img/vscode-emmet.webp width=520
Набрали ! — VS Code предлагает Emmet Abbreviation. Нажмите Tab
:::

| Сокращение | Что получится |
|---|---|
| `!` | Каркас HTML-страницы |
| `h1{Привет}` | `<h1>Привет</h1>` |
| `.card` | `<div class="card"></div>` |
| `a[href=about.html]` | `<a href="about.html"></a>` |
| `ul>li*3` | Список `ul` с тремя пунктами `li` |
| `ul>li.item$*3` | Пункты с классами `item1`, `item2`, `item3` |
| `p>lorem10` | Абзац из десяти слов текста-заглушки |

Знак `>` — «внутри», `*3` — «три раза», `.` — класс, `{}` — текст. Вот что даёт `ul>li.item$*3`:

```html
<ul>
  <li class="item1"></li>
  <li class="item2"></li>
  <li class="item3"></li>
</ul>
```

## Настройки

Настройки открываются <kbd>⌘</kbd>+<kbd>,</kbd>. В поле поиска вверху наберите название настройки.

:::shot img/vscode-settings.webp width=620
Настройка Format On Save: код выравнивается при каждом сохранении
:::

Вместо щелчков можно вставить настройки текстом. Откройте палитру (<kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>P</kbd>) → `Preferences: Open User Settings (JSON)` и добавьте внутрь фигурных скобок:

```json title="settings.json"
{
  "editor.formatOnSave": true,
  "files.autoSave": "onFocusChange",
  "editor.tabSize": 2,
  "editor.wordWrap": "on",
  "editor.linkedEditing": true
}
```

| Настройка | Что делает |
|---|---|
| `formatOnSave` | Выравнивает код при сохранении |
| `autoSave` | Сохраняет файл, когда вы переключаетесь в браузер |
| `tabSize` | Отступ — два пробела |
| `wordWrap` | Длинные строки переносятся, а не уезжают вправо |
| `linkedEditing` | Меняете открывающий тег — меняется и закрывающий |

## Папка для домашних заданий

Домашние задания лежат в готовой папке-шаблоне: там уже есть заготовки, тесты и настройки Biome. Ссылку на шаблон даст ментор.

1. Скачайте шаблон архивом и распакуйте в `~/dev/homework`.
2. Откройте папку в VS Code: `cd ~/dev/homework`, затем `code .`
3. VS Code предложит установить рекомендованные расширения — нажмите **Install**.
4. В встроенном терминале выполните одну команду — она скачает Biome в папку проекта:

```bash
npm install
```

Что такое `npm` и `package.json`, разберём в уроке {{n:tooling}}. Пока достаточно знать: команда читает список нужных инструментов из файла `package.json` и скачивает их в папку `node_modules`.

## Линтер Biome

[[Линтер]] читает код и находит ошибки и плохие практики ещё до того, как вы откроете страницу. [[Форматирование|Форматтер]] расставляет отступы и переносы. Biome делает и то и другое.

:::diagram id=biome-flow
type: flow
caption: Что делает Biome при сохранении файла
items:
  - {title: Вы пишете код, text: "с опечатками и кривыми отступами", kind: muted, icon: pencil}
  - {arrow: right, label: "⌘S"}
  - {title: Biome, text: проверяет и выравнивает, kind: accent, icon: checklist}
  - {arrow: right}
  - {title: Ровный код, text: и подчёркнутые ошибки, kind: back, icon: check}
:::

В редакторе ошибка подчёркивается волнистой линией. Наведите на неё мышь — появится объяснение. Все проблемы проекта собраны в панели **Problems**: <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>M</kbd>. Быстрое исправление, если оно есть, — <kbd>⌘</kbd>+<kbd>.</kbd>

Biome можно запустить и из терминала — он проверит все файлы сразу. Вот что он скажет про страницу с типичными ошибками новичка:

:::terminal title="zsh — homework" caption="Biome нашёл две проблемы доступности. Вывод сокращён, пояснения — на английском"
mary@MacBook-Air homework % npx biome check index.html
index.html:2:1 lint/a11y/useHtmlLang
! × Provide a lang attribute when using the html element.
  > 2 │ <html>
index.html:9:7 lint/a11y/useAltText
! × Provide a text alternative through the alt, aria-label, or aria-labelledby attribute.
  > 9 │ <img src="coffee.jpg">
:::

Каждое сообщение устроено одинаково: файл, строка и колонка, название правила, что не так. Первое правило просит указать язык страницы: `<html lang="ru">`. Второе — описать картинку для незрячих: `<img src="coffee.jpg" alt="Чашка кофе">`. Что это за атрибуты, разберём в уроках {{n:html-basics}}–{{n:html-forms}}.

:::tip Не спорьте с линтером
Если Biome подчеркнул код, почти всегда он прав. Не понимаете сообщение — скопируйте его в поиск или спросите ментора.
:::

## Live Server

[[Live Server]] запускает маленький сервер для вашей папки и открывает страницу в браузере. Сохранили файл — страница обновилась сама.

:::diagram id=live-server
type: flow
caption: Больше не нужно нажимать ⌘R после каждого изменения
items:
  - {title: Правите index.html, kind: accent, icon: code}
  - {arrow: right, label: "⌘S"}
  - {title: Live Server, text: замечает изменение, kind: back, icon: server}
  - {arrow: right}
  - {title: Chrome, text: обновляет страницу сам, kind: front}
:::

1. Откройте HTML-файл в редакторе.
2. Нажмите **Go Live** справа в строке состояния или правый клик по файлу → **Open with Live Server**.
3. Откроется Chrome с адресом вида `http://127.0.0.1:5500/index.html`.
4. Остановить — щёлкнуть **Port: 5500** в строке состояния.

## Частые ошибки

:::mistake Открыт файл, а не папка
Проводник пустой, поиск ничего не находит, Live Server открывает не ту страницу. Откройте папку проекта: <kbd>⌘</kbd>+<kbd>O</kbd>.
:::

:::mistake Правки не видны в браузере
Посмотрите на вкладку: точка ● значит, что файл не сохранён. Нажмите <kbd>⌘</kbd>+<kbd>S</kbd> или включите автосохранение.
:::

:::mistake Biome молчит
Проверьте три вещи: установлено расширение Biome, в папке выполнен `npm install`, в VS Code открыта именно папка `homework`, а не вложенная папка задания.
:::

## Квиз

:::quiz
- q: Почему в VS Code лучше открывать папку проекта, а не отдельный файл?
  options:
    - Иначе файл не сохранится
    - Работают проводник, поиск по проекту, терминал в нужной папке и Live Server
    - Отдельные файлы открываются только для чтения
    - Так быстрее запускается VS Code
  answer: 1
  why: Многие возможности VS Code работают с папкой целиком. Одиночный файл — это редактор без проекта.
- q: Вы не помните, как отформатировать файл. Что сделать?
  options:
    - Искать в меню по очереди
    - Открыть палитру команд ⇧⌘P и начать вводить «format»
    - Переустановить VS Code
    - Выровнять отступы вручную
  answer: 1
  why: Палитра находит любую команду по названию и показывает её сочетание клавиш.
- q: На вкладке файла видна точка ●. Что это значит?
  options:
    - В файле ошибка
    - Файл не сохранён
    - Файл открыт в браузере
    - Файл только для чтения
  answer: 1
  why: Точка — несохранённые изменения. Браузер видит только сохранённую версию.
- q: Что сделает Emmet из `ul>li*3`?
  options:
    - Три отдельных списка
    - Список ul с тремя пунктами li
    - Один пункт с текстом «3»
    - Ничего — это ошибка
  answer: 1
  why: "`>` — вложенность, `*3` — повторить три раза."
- q: Как изменить слово сразу в нескольких местах файла?
  options:
    - Только через поиск и замену
    - Выделить слово и нажимать ⌘D, затем печатать
    - Удалить и написать заново каждое
    - "⌘/"
  answer: 1
  why: "⌘D добавляет курсор на следующее совпадение. ⌘/ закомментирует строку."
- q: Что делает линтер?
  options:
    - Запускает страницу в браузере
    - Находит ошибки и плохие практики в коде ещё до запуска
    - Сохраняет файлы
    - Скачивает библиотеки
  answer: 1
  why: Линтер читает код и подсказывает, что не так. Страницу показывает Live Server, скачивает библиотеки npm.
- q: "Biome пишет: `index.html:9:7 lint/a11y/useAltText`. Где ошибка?"
  options:
    - В строке 7, символ 9
    - В файле index.html, строка 9, колонка 7
    - Девятая ошибка из семи
    - В файле a11y
  answer: 1
  why: Сначала файл, потом строка, потом колонка. Дальше — название правила.
- q: Зачем Live Server?
  options:
    - Публикует сайт в интернете
    - Открывает страницу в браузере и обновляет её при каждом сохранении
    - Проверяет ошибки в HTML
    - Форматирует код
  answer: 1
  why: Live Server работает только на вашем компьютере и избавляет от ручного обновления страницы.
:::
