Что открыть заранее: слайды, текст урока, VS Code на своём компьютере с открытой папкой любого проекта. Шаблон домашних заданий в виде архива — отправьте ученику ссылку до занятия.

Цель занятия: ученик уверенно открывает папку проекта, пользуется палитрой команд и пятью главными сочетаниями, у него работают Biome и Live Server.

Формат: половину времени ученик повторяет всё у себя, вы смотрите его экран.
