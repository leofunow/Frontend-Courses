| ⌘/ | Закомментировать |
| ⌥↑ / ⌥↓ | Переместить строку |

| ⇧⌥F | Отформатировать |

## Несколько курсоров: ⌘D

:::cols
```html
<li class="item">Кофе</li>
<li class="item">Чай</li>
<li class="item">Какао</li>
```
+++
```html
<li class="card">Кофе</li>
<li class="card">Чай</li>
<li class="card">Какао</li>
```
:::

Выделить `item` → ⌘D ⌘D → напечатать `card`

## Сокращения Emmet

| Сокращение | Результат |
|---|---|
| `h1{Привет}` | заголовок с текстом |
| `.card` | `<div class="card">` |
| `ul>li*3` | список из трёх пунктов |
| `a[href=about.html]` | ссылка с адресом |

`>` — внутри, `*` — повторить, `.` — класс, `{}` — текст

---

## Одна строка — целый список

:::cols
```text
ul>li.item$*3
```
+++
```html
<ul>
  <li class="item1"></li>
  <li class="item2"></li>
  <li class="item3"></li>
</ul>
```
:::

<!-- class: cards -->
## Частые ошибки

- **Открыт файл** а не папка — проводник пустой
- **Точка ●** файл не сохранён, браузер видит старое
- **Emmet молчит** файл не `.html` — внизу Plain Text
- **Biome молчит** нет расширения или `npm install`
