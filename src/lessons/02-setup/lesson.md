## Клавиши Mac

В курсе сочетания клавиш записаны по-маковски. Запомните четыре значка:

| Значок | Клавиша | Пример |
|---|---|---|
| ⌘ | Command (Cmd) | <kbd>⌘</kbd>+<kbd>C</kbd> — копировать |
| ⌥ | Option (Alt) | <kbd>⌥</kbd>+<kbd>⌘</kbd>+<kbd>I</kbd> — DevTools |
| ⇧ | Shift | <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>P</kbd> — палитра команд в VS Code |
| ⌃ | Control | <kbd>⌃</kbd>+<kbd>C</kbd> — остановить команду в Терминале |

Ещё три сочетания понадобятся сегодня:
- <kbd>⌘</kbd>+<kbd>Пробел</kbd> — Spotlight, поиск программ;
- <kbd>⌘</kbd>+<kbd>Q</kbd> — закрыть программу целиком;
- <kbd>⌘</kbd>+<kbd>,</kbd> — настройки любой программы.

:::mistake Command и Control — разные клавиши
В Терминале <kbd>⌃</kbd>+<kbd>C</kbd> (Control) останавливает команду, а <kbd>⌘</kbd>+<kbd>C</kbd> (Command) копирует текст. Путать их не страшно, но результат будет разным.
:::

## Терминал: что это и зачем

[[Терминал]] — программа, где вы управляете компьютером текстом: пишете [[команда|команду]], нажимаете <kbd>Return</kbd>, компьютер отвечает. Это тот же Finder, только без мыши.

    items:
      - {title: "`cd dev`", text: перейти в папку, kind: accent, icon: terminal}
      - {arrow: right}

      - {arrow: right}

:::

Зачем фронтенд-разработчику Терминал, если есть мышь? Многие инструменты работают только через команды: `npm` ставит библиотеки, `git` сохраняет историю, Vite запускает проект. Без Терминала их не запустить.

:::note Терминал и zsh
Терминал — это окно. Внутри работает [[оболочка]] zsh: она понимает команды и выполняет их. Поэтому в ошибках часто пишут `zsh: …`.
:::

## Как устроена команда

Команда — это строка из частей, разделённых пробелами. Сначала имя команды, потом [[флаг|флаги]] (настройки с дефисом), потом [[аргумент|аргументы]] — над чем работать.

:::diagram id=command-anatomy
type: flow
caption: "`ls -a ~/dev` — показать все файлы в папке dev, включая скрытые"
items:
  - {title: "`ls`", text: "имя команды: что сделать", kind: accent, icon: false}
  - {title: "`-a`", text: "флаг: как сделать (all — все)", kind: front, icon: false}
  - {title: "`~/dev`", text: "аргумент: с чем сделать", kind: back, icon: false}
:::

Правила, которые стоит запомнить сразу:

- **Регистр важен.** `ls` работает, `LS` — нет. Папки `Dev` и `dev` — разные.
- **Пробел разделяет части.** `cd my folder` — это попытка перейти в папку `my`. Имя с пробелом берут в кавычки: `cd "my folder"`.
- **Нет ответа — значит, всё хорошо.** Команды вроде `mkdir` и `cd` молчат при успехе.
- **Ошибку нужно прочитать.** Терминал пишет, что пошло не так:

:::terminal caption="Опечатка в имени папки: Терминал говорит, что такой нет"
mary@MacBook-Air ~ % cd dve
! cd: no such file or directory: dve
mary@MacBook-Air ~ % cd dev
mary@MacBook-Air dev %
:::

:::tip Клавиши, которые экономят время
- <kbd>Tab</kbd> дописывает имя: наберите `cd De` и нажмите <kbd>Tab</kbd>.
- <kbd>↑</kbd> и <kbd>↓</kbd> листают прошлые команды.
- <kbd>⌃</kbd>+<kbd>C</kbd> останавливает команду, которая «зависла».
- <kbd>⌘</kbd>+<kbd>K</kbd> очищает экран.
- Перетащите папку из Finder в окно Терминала — вставится её полный путь.
:::

## Основные команды

Этих команд хватит на весь курс. Попробуйте каждую прямо сейчас.

| Команда | Что делает | Пример |
|---|---|---|
| `pwd` | Показывает, в какой папке вы сейчас | `pwd` → `/Users/mary` |
| `ls` | Список файлов и папок. `-a` — со скрытыми, `-l` — подробно | `ls -la` |
| `cd` | Перейти в папку. `..` — на уровень выше, `~` — домой | `cd ~/dev` |
| `mkdir` | Создать папку. `-p` — сразу со вложенными | `mkdir -p site/css` |
| `touch` | Создать пустой файл | `touch index.html` |
| `open` | Открыть в программе по умолчанию. `.` — эта папка в Finder | `open index.html` |
| `code` | Открыть в VS Code (заработает после установки) | `code .` |
| `cp` | Скопировать файл | `cp a.html b.html` |
| `mv` | Переместить или переименовать | `mv b.html about.html` |
| `rm` | Удалить файл **без Корзины** | `rm about.html` |
| `clear` | Очистить экран | `clear` |

Так выглядит первое знакомство целиком: создаём папку для учёбы и смотрим, что получилось.

:::terminal caption="Создаём папку ~/dev и проект hello внутри неё"
mary@MacBook-Air ~ % pwd                  # где я?
/Users/mary
mary@MacBook-Air ~ % mkdir dev            # создать папку dev
mary@MacBook-Air ~ % cd dev               # перейти в неё
mary@MacBook-Air dev % mkdir hello
mary@MacBook-Air dev % cd hello
mary@MacBook-Air hello % touch index.html  # пустой файл
mary@MacBook-Air hello % ls
index.html
mary@MacBook-Air hello % open .           # открыть папку в Finder
:::

:::mistake rm удаляет навсегда
Файл, удалённый через `rm`, не попадает в Корзину. Проверяйте, что стоит после `rm`, прежде чем нажать <kbd>Return</kbd>. Никогда не запускайте `rm -rf` с путями из интернета.
:::

:::tip Как узнать больше о команде
`man ls` открывает справку по команде `ls`. Листать — пробелом, выйти — клавишей <kbd>Q</kbd>.
:::

## Пути: абсолютные и относительные

[[Путь]] — адрес файла. Он бывает двух видов.

- **[[Абсолютный путь|Абсолютный]]** — от корня диска: `/Users/mary/dev/hello/index.html`. Работает, где бы вы ни находились. `~` — то же, что `/Users/mary`.
- **[[Относительный путь|Относительный]]** — от текущей папки: если вы в `dev`, тот же файл — `hello/index.html`.

:::diagram id=paths
type: tree
caption: "Вы находитесь в папке hello"
items:
  - name: dev
    note: "..  — на уровень выше"
    items:
      - name: hello
        mark: true
        note: ".  — текущая папка"
        items:
          - {name: index.html, note: "index.html или ./index.html"}
          - {name: style.css}
      - name: shop
        items:
          - {name: index.html, note: "../shop/index.html"}
:::

```bash
cd ~/dev/hello   # абсолютный путь: сработает откуда угодно
cd ..            # подняться на уровень выше, в dev
cd hello         # относительный путь: из dev в hello
cd ~             # вернуться домой
```

Эти же правила действуют в HTML: ссылки на картинки и стили будут относительными путями (урок {{n:html-basics}}).

## Установка VS Code

Откройте [code.visualstudio.com/download](https://code.visualstudio.com/download) и нажмите кнопку для Mac.

:::shot img/vscode-download.webp width=480
Кнопка Mac: подходит и для Apple Silicon (M1–M4), и для Intel
:::

1. В «Загрузках» появится архив `.zip`. Дважды щёлкните — рядом появится программа **Visual Studio Code**.
2. Перетащите её в папку «Программы» в боковой панели Finder.
3. Запустите VS Code через Spotlight и нажмите «Открыть» в предупреждении.

Теперь научим Терминал открывать VS Code командой `code`. В VS Code нажмите <kbd>⇧</kbd>+<kbd>⌘</kbd>+<kbd>P</kbd>, начните вводить `shell command` и выберите `Shell Command: Install 'code' command in PATH`.

```bash
code .          # открыть текущую папку в VS Code
```

:::mistake VS Code запущен прямо из «Загрузок»
Так он работает, но не обновляется, а команда `code` потом ломается. Сначала перетащите программу в «Программы», потом запускайте.
:::

## Проверка установки

Закройте Терминал (<kbd>⌘</kbd>+<kbd>Q</kbd>), откройте заново и выполните четыре команды. Каждая должна напечатать номер версии. Цифры у вас будут другие — это нормально.

```bash
node -v
npm -v
git --version
code --version
```

```text
v24.11.0
11.6.1
git version 2.39.5 (Apple Git-154)
1.105.1
```

| Если видите | Что делать |
|---|---|
| `zsh: command not found: node` | Закройте Терминал через ⌘Q и откройте снова. Не помогло — переустановите Node.js |
| `zsh: command not found: code` | Выполните в VS Code команду `Shell Command: Install 'code' command in PATH` |
| окно с предложением установить инструменты | Это Git просит Command Line Tools — нажмите «Установить» |

## Частые ошибки

:::mistake Файл сохранился как index.html.txt
Так бывает, если писать код в «TextEdit». Пишите только в VS Code и включите показ расширений в Finder.
:::

:::mistake sudo перед командой
Советы из интернета вида `sudo npm install …` дают команде права администратора. В курсе это не нужно, а права на папки потом ломаются. Если команда требует `sudo` — спросите ментора.
:::

:::mistake Пробел в пути без кавычек
`cd Мои проекты` Терминал поймёт как две папки. Если без пробела никак — берите путь в кавычки: `cd "Мои проекты"`. А лучше переименуйте папку.
:::

## Шпаргалка

| Команда | Что делает |
|---|---|
| `pwd` | Показать, в какой папке вы сейчас |
| `ls` | Список файлов и папок, `ls -a` — со скрытыми |
| `cd папка` | Перейти в папку. `cd ..` — на уровень выше, `cd ~` — домой |
| `mkdir имя` | Создать папку |
| `touch файл` | Создать пустой файл |
| `open .` | Открыть текущую папку в Finder |
| `code .` | Открыть текущую папку в VS Code |
| `clear` | Очистить экран, или <kbd>⌘</kbd>+<kbd>K</kbd> |
| <kbd>⌃</kbd>+<kbd>C</kbd> | Остановить работающую команду |

## Квиз

:::quiz
- q: Вы открыли Терминал и видите `mary@MacBook-Air dev %`. Что это значит?
  options:
    - Произошла ошибка в папке dev
    - Терминал готов к команде, вы сейчас в папке dev
    - Терминал просит пароль
    - Нужно установить папку dev
  answer: 1
  why: Это приглашение. Перед `%` — имя текущей папки, после `%` можно вводить команду.
- q: "Что в команде `ls -a ~/dev` является флагом?"
  options:
    - "`ls`"
    - "`-a`"
    - "`~/dev`"
    - Вся строка целиком
  answer: 1
  why: Флаг — настройка команды, начинается с дефиса. `ls` — имя команды, `~/dev` — аргумент, с чем работать.
- q: "Терминал ответил `cd: no such file or directory: Dev`. Что это значит?"
  options:
    - Терминал сломался, нужно перезапустить Mac
    - Папки с таким именем нет в текущей папке — опечатка или другой регистр
    - Нужно выполнить команду с sudo
    - Папка Dev удалена
  answer: 1
  why: "Терминал различает регистр: `Dev` и `dev` — разные имена. Проверьте `ls`, какие папки есть на самом деле."
- q: Какая команда покажет полный путь к текущей папке?
  options:
    - "`ls`"
    - "`cd`"
    - "`pwd`"
    - "`open`"
  answer: 2
  why: "`pwd` — print working directory. `ls` показывает содержимое папки, а не её путь."
- q: Вы в папке `~/dev/hello`. Куда попадёте после `cd ..`?
  options:
    - "`~/dev`"
    - "`~`"
    - "`~/dev/hello/..`, это новая папка"
    - Команда выдаст ошибку
  answer: 0
  why: Две точки — папка уровнем выше. Выше `hello` находится `dev`.
- q: Какой путь абсолютный?
  options:
    - "`hello/index.html`"
    - "`../style.css`"
    - "`~/dev/hello/index.html`"
    - "`./index.html`"
  answer: 2
  why: "Абсолютный путь начинается от корня: с `/` или `~`. Остальные считаются от текущей папки."
- q: Какую версию Node.js выбрать на сайте?
  options:
    - Самую новую, с наибольшим номером
    - С меткой LTS
    - Любую — они одинаковые
    - Самую старую, она проверенная
  answer: 1
  why: LTS — стабильная версия с долгой поддержкой. Её выбирают для работы и учёбы.
- q: 'Вы установили Node.js, но Терминал пишет `command not found: node`. Что сделать первым?'
  options:
    - Переустановить macOS
    - Закрыть Терминал через ⌘Q и открыть снова
    - Выполнить команду с sudo
    - Установить Node.js второй раз
  answer: 1
  why: Терминал узнаёт о новых программах при запуске. В большинстве случаев достаточно его перезапустить.
- q: Где лучше хранить учебные проекты?
  options:
    - "`~/Desktop/Мои проекты`"
    - "`~/dev`"
    - В папке «Загрузки»
    - В iCloud Drive
  answer: 1
  why: Короткий путь без пробелов и кириллицы, не синхронизируется с iCloud — меньше странных ошибок.
- q: Зачем включать показ расширений в Finder?
  options:
    - Чтобы файлы открывались быстрее
    - Чтобы видеть настоящее имя файла и не получить `index.html.txt`
    - Без этого не работает VS Code
    - Чтобы видеть скрытые файлы
  answer: 1
  why: Mac прячет расширения. Файл может называться иначе, чем вы думаете, и браузер откроет его неправильно.
:::
