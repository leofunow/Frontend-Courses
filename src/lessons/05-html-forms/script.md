Что открыть заранее: слайды, текст урока (песочницы с формами), VS Code с папкой `homework`. Проверьте, что VoiceOver на вашем Mac включается сочетанием ⌘F5.

Цель занятия: ученик собирает форму с подписанными полями нужных типов, включает встроенную проверку, делает таблицу и проверяет страницу клавиатурой.

## Титульный слайд (1 мин)

**На слайде:** название урока.

**Рассказать:** сегодня страница начинает принимать данные от человека.

## Форма — главный способ получить что-то от пользователя (1 мин)

**На слайде:** тезис.

**Рассказать:** вход, заказ, поиск, запись — всё это формы.

## Как устроена форма (4 мин)

**На слайде:** пользователь → проверка браузера → отправка.

**Рассказать:** сервера у нас пока нет, поэтому отправка сейчас будет обновлять страницу. Свой сервер напишем позже.

## Минимальная форма (5 мин)

**На слайде:** форма с одним полем и кнопкой.

**Показать вживую:** ученик в VS Code создаёт форму. Отправить с `method="get"` и посмотреть адрес: `?name=Мария`.

**Спросить:** «Откуда в адресе взялось слово name?» Ответ: из атрибута name поля.

## Подпись: for + id (5 мин)

**На слайде:** label и input.

**Показать вживую:** щёлкнуть по подписи — курсор в поле. Удалить `for` — перестало работать.

**Рассказать:** placeholder исчезает при вводе — это пример значения, не подпись.

## Типы полей (6 мин)

**На слайде:** таблица типов.

**Показать вживую:** песочница «Типы полей». Если есть телефон — открыть страницу на нём и показать разные клавиатуры.

## Выбор из вариантов (6 мин)

**На слайде:** radio, checkbox, select, textarea.

**Показать вживую:** в песочнице поменять name у одного radio — теперь можно выбрать два. Вернуть.

**Спросить:** «Размер пиццы и добавки к ней — какие элементы?» Ответ: radio и checkbox.

## Кнопки (4 мин)

**На слайде:** три типа кнопок.

**Рассказать:** без type кнопка отправляет форму — отсюда случайные перезагрузки страницы. Biome напоминает.

## Проверка без JavaScript (7 мин)

**На слайде:** атрибуты required, minlength, type=email, min и max.

**Показать вживую:** песочница «Встроенная валидация»: отправить пустую, с одной буквой в имени, с неправильной почтой.

**Рассказать:** проверку обходят через DevTools — помните урок {{n:intro}}. Защита — на сервере.

## Группы полей (3 мин)

**На слайде:** fieldset и legend.

**Рассказать:** VoiceOver прочитает вопрос вместе с вариантом ответа.

## Таблицы (4 мин)

**На слайде:** дерево table → thead/tbody → tr → th/td.

**Рассказать:** th — заголовок, td — данные. caption — название таблицы.

## Таблица цен (6 мин)

**На слайде:** код таблицы цен.

**Показать вживую:** ученик пишет таблицу через Emmet: `table>thead>tr>th*3` и дальше вручную.

**Рассказать:** таблицами не раскладывают страницу — для этого есть Grid.

## Доступность: кто и что (7 мин)

**На слайде:** три группы пользователей и что им нужно.

**Показать вживую:** включить VoiceOver (⌘F5) на форме ученика: как читаются подписанные и неподписанные поля. Выключить.

## Фокус (3 мин)

**На слайде:** поле в фокусе с рамкой.

**Показать вживую:** ученик проходит свою форму клавишей Tab и отправляет её, не трогая мышь.

## Проверка за пять минут (5 мин)

**На слайде:** четыре шага проверки.

**Рассказать:** эти четыре шага — обязательная самопроверка перед сдачей любой вёрстки, начиная с этого урока.

**Спросить:** «Кнопку сделали из div. Какой из четырёх шагов это найдёт?» Ответ: Tab и VoiceOver.
