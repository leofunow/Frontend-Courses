## Одна страница — любой экран

Больше половины посетителей открывают сайты с телефона. Делать отдельный сайт под каждое устройство дорого, поэтому верстают одну страницу, которая перестраивается под ширину экрана. Это [[адаптивная вёрстка]].

:::shot img/resp-devices.webp
Один и тот же HTML и CSS. Меняется только ширина окна — и число колонок
:::

Весь урок про три вопроса:
1. Как узнать, какая ширина у экрана, — `meta viewport` и DevTools.
2. Как поменять стили на нужной ширине — медиазапросы.
3. Как сделать так, чтобы ничего не вылезало, — резиновые размеры.

## meta viewport

Телефоны появились, когда все сайты были рассчитаны на ноутбуки. Чтобы старые сайты не ломались, телефон по умолчанию притворяется экраном шириной 980px и уменьшает страницу. Строка в `<head>` отменяет это притворство:

```html title="index.html"
<meta name="viewport" content="width=device-width, initial-scale=1">
```

## Режим устройств в DevTools

Проверять сайт на телефоне после каждой правки долго. В Chrome есть [[Режим устройств|режим устройств]]: он показывает страницу в окне нужной ширины.

:::shot img/devtools-device-toggle.webp width=720
Кнопка режима устройств — слева от вкладки Elements. Над страницей появляется панель с размерами. Картинка из документации Chrome
:::

1. Откройте DevTools: ⌥⌘I.
2. Нажмите кнопку с телефоном и планшетом или ⇧⌘M.
3. В списке Dimensions выберите устройство, например iPhone SE. Или оставьте Responsive и тяните край страницы мышью.
4. Проверьте три ширины: 375, 768 и 1280px.

:::tip Самая быстрая проверка
Просто сузьте окно браузера до упора. Если появилась горизонтальная прокрутка — что-то слишком широкое. Найти виновника поможет Elements: наводите на элементы и смотрите на их ширину.
:::

## Медиазапросы

[[Медиазапрос]] — условие для блока CSS. Правила внутри срабатывают, только когда условие верно:

```css
.cards {
  grid-template-columns: 1fr;          /* всегда: одна колонка */
}

@media (min-width: 640px) {
  .cards {
    grid-template-columns: 1fr 1fr;    /* от 640px и шире — две */
  }
}
```

`min-width: 640px` читается как «ширина окна не меньше 640px». Правило внутри `@media` не заменяет весь блок `.cards`, а дописывает его, как любое правило ниже по файлу.

:::sandbox Медиазапрос height=260
```html
<p class="size">Ширина превью: <b id="w"></b></p>
<div class="box">Медиазапрос</div>
```
```css
.box {
  padding: 24px;
  color: #fff;
  background: #0969da;
  border-radius: 8px;
}

@media (min-width: 300px) {
  .box {
    background: #1a7f37;
  }
  .box::after {
    content: " → сработал min-width: 300px";
  }
}
```
```js
const show = () => { document.getElementById('w').textContent = innerWidth + 'px'; };
show();
addEventListener('resize', show);
```
:::

Ширина превью написана сверху. Поменяйте `300px` на число больше неё — условие перестанет выполняться, и блок станет синим.

## Сначала телефон

Есть два способа писать медиазапросы. [[Mobile-first]] — базовые стили для телефона, а `min-width` добавляет колонки на широких экранах. Desktop-first — наоборот, с `max-width`. Берите mobile-first: на телефоне самая простая раскладка, её проще расширять, чем урезать.

:::shot img/resp-breakpoints.webp
Ширины, на которых стили меняются, называют [[брейкпоинт|брейкпоинтами]]
:::

Так выглядит CSS страницы из начала урока:

```css title="css/style.css"
/* телефон — без медиазапроса */
.cards { display: grid; grid-template-columns: 1fr; gap: 16px; }

/* планшет */
@media (min-width: 640px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}

/* ноутбук */
@media (min-width: 1024px) {
  .cards { grid-template-columns: repeat(3, 1fr); }
  .page { max-width: 1100px; margin: 0 auto; }
}
```

Медиазапросы пишут в конце файла, от меньшей ширины к большей. Брейкпоинты выбирают по содержимому: сужайте окно и ставьте брейкпоинт там, где вёрстка начинает ломаться. 640 и 1024 — удобные числа для старта.

## Резиновые размеры

Меньше медиазапросов — меньше работы. Многие размеры можно задать так, что они подстроятся сами.

| Запись | Что значит | Пример |
|---|---|---|
| `%` | доля ширины родителя | `width: 50%` |
| `max-width` | «не шире», но может быть уже | `max-width: 960px` |
| `vw` | 1% ширины окна | `font-size: 5vw` |
| `rem` | размер шрифта страницы, обычно 16px | `padding: 1rem` |
| `clamp(min, идеал, max)` | идеал, но не меньше min и не больше max | `clamp(2rem, 5vw, 3.5rem)` |

Главная замена — `width` на `max-width`. `width: 960px` на телефоне шириной 375px даёт прокрутку, `max-width: 960px` — просто сжимается.

:::sandbox Заголовок, который тянется height=250
```html
<h1 class="title">Кофе, который хочется повторить</h1>
```
```css
.title {
  margin: 0;
  /* не меньше 1.5rem, не больше 3rem, между ними — 6% ширины */
  font-size: clamp(1.5rem, 6vw, 3rem);
  line-height: 1.1;
}
```
:::

## Картинки

Картинка по умолчанию показывается в своём настоящем размере. Фото шириной 1200px на телефоне вылезет за экран. Одно правило решает это для всех картинок сразу:

```css
img {
  max-width: 100%;   /* не шире родителя */
  height: auto;      /* высота — по пропорциям */
  display: block;    /* без пустой полоски снизу */
}
```

Если картинке нужны точные размеры — например, квадратные превью, — задайте `width` и `height`, а `object-fit` скажет, как вписать в них фото:

:::shot img/resp-fit.webp
Квадратная картинка в прямоугольной рамке. fill — растянуть, contain — вписать целиком, cover — заполнить и обрезать края
:::

Для превью и обложек почти всегда нужен `cover`.

:::note Разные файлы для разных экранов
Атрибут `srcset` даёт браузеру выбор: телефону — лёгкую картинку, ноутбуку — крупную. Пока достаточно знать, что он есть. Подробнее — в MDN по запросу «srcset».
:::

## Сетки без медиазапросов

Помните строку из прошлого урока? Она сама решает, сколько колонок влезет:

```css
.menu {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  gap: 16px;
}
```

На телефоне влезет одна колонка по 260px, на ноутбуке — три или четыре. То же для Flexbox: `flex-wrap: wrap` переносит элементы, которым не хватило места.

| Задача | Чем решать |
|---|---|
| Карточки одинаковой ширины | `auto-fill` и `minmax` — без медиазапросов |
| Точное число колонок по макету: 1, 2, 3 | медиазапросы |
| Элементы меняются местами или прячутся | медиазапросы и `grid-template-areas` |

## CSS-переменные

В реальном CSS один цвет повторяется десятки раз. Дизайнер поменял фирменный цвет — ищи все места. [[CSS-переменная]] решает это: значение записывают один раз и дальше ссылаются на него.

```css
:root {
  --color-accent: #bc4c00;     /* объявили: имя начинается с -- */
}

.btn {
  background: var(--color-accent);   /* используем */
}
```

`:root` — корень документа, то есть `<html>`. Переменные оттуда видны во всех элементах. Внутри медиазапроса переменную можно переопределить — и все места, где она используется, поменяются разом.

:::sandbox Фирменный цвет в одном месте height=240
```html
<header class="header">
  <strong class="logo">Зерно</strong>
  <a class="btn" href="#order">Заказать</a>
</header>
<p class="price">Капучино — 220 ₽</p>
```
```css
:root {
  --color-accent: #bc4c00;
  --radius: 8px;
}

.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding-bottom: 12px;
  border-bottom: 2px solid var(--color-accent);
}

.logo, .price { color: var(--color-accent); }

.btn {
  padding: 8px 16px;
  color: #fff;
  background: var(--color-accent);
  border-radius: var(--radius);
  text-decoration: none;
}
```
:::

Поменяйте `#bc4c00` на `#0969da` — перекрасятся логотип, рамка, кнопка и цена.

## Частые ошибки

:::mistake Нет meta viewport
На телефоне страница мелкая, медиазапросы не срабатывают. Первым делом проверьте `<head>`.
:::

:::mistake Фиксированная ширина в пикселях
`width: 600px` у блока на телефоне шириной 375px — горизонтальная прокрутка и обрезанный текст. Нужно `max-width`.

:::shot img/resp-fixed.webp width=300
Промо-блок шириной 600px уехал за правый край
:::
:::

:::mistake Только наведение мышью
На телефоне нет `:hover`. Если меню открывается только по наведению, с телефона до него не добраться. Всё важное — по клику.
:::

:::mistake Мелкие кнопки и ссылки
Палец больше курсора. Кнопки и ссылки в меню — не меньше 44 на 44 пикселя, с промежутками между ними.
:::

```css
}
```

## Квиз

:::quiz
- q: Что будет на телефоне, если в `<head>` нет meta viewport?
  options:
    - Страница не откроется
    - Телефон покажет её уменьшенной, как на экране шириной около 980px
    - Всё будет как обычно
    - Пропадут все стили
  answer: 1
  why: Без viewport телефон притворяется широким экраном и уменьшает страницу. Медиазапросы для узких экранов не срабатывают.
- q: 'Когда сработает `@media (min-width: 640px) { … }`?'
  options:
    - Когда ширина окна 640px и больше
    - Когда ширина окна меньше 640px
    - Только на телефонах
    - Только при ширине ровно 640px
  answer: 0
  why: min-width — «не меньше». От 640px и шире.
- q: Что значит mobile-first?
  options:
    - Сначала сделать приложение для телефона, потом сайт
    - Базовые стили — для телефона, медиазапросы с min-width добавляют раскладку для широких экранов
    - Скрыть половину сайта на телефоне
    - Писать медиазапросы с max-width
  answer: 1
  why: Начинаем с самой простой раскладки и расширяем её на больших экранах.
- q: 'Блок с `width: 900px` на телефоне создаёт горизонтальную прокрутку. Как исправить проще всего?'
  options:
    - "`width: 375px`"
    - "`max-width: 900px`"
    - "`overflow: hidden` у body"
    - "`zoom: 0.4`"
  answer: 1
  why: max-width разрешает быть уже. На ноутбуке — 900px, на телефоне — по ширине экрана.
- q: 'Что делает `font-size: clamp(2rem, 5vw, 3.5rem)`?'
  options:
    - Размер шрифта — 5% ширины окна, но не меньше 2rem и не больше 3.5rem
    - Выбирает случайный размер
    - Три размера для трёх экранов по очереди
    - Всегда 2rem
  answer: 0
  why: clamp держит идеальное значение в заданных границах.
- q: Какое правило не даст картинкам вылезать за родителя?
  options:
    - "`img { width: 1200px; }`"
    - "`img { max-width: 100%; height: auto; }`"
    - "`img { object-fit: cover; }`"
    - "`img { overflow: hidden; }`"
  answer: 1
  why: max-width 100% — не шире родителя, height auto сохраняет пропорции.
- q: 'Как объявить и использовать CSS-переменную?'
  options:
    - "`$accent: red;` и `color: $accent;`"
    - "`:root { --accent: red; }` и `color: var(--accent);`"
    - "`:root { accent = red; }` и `color: accent;`"
    - "`@var accent red;` и `color: @accent;`"
  answer: 1
  why: Имя начинается с двух дефисов, значение берут через var().
- q: 'Когда `repeat(auto-fill, minmax(260px, 1fr))` удобнее медиазапросов?'
  options:
    - Когда по макету на каждом экране строго заданное число колонок
    - Когда карточки одинаковые и колонок может быть сколько влезет
    - Когда нужно спрятать элемент на телефоне
    - Никогда
  answer: 1
  why: Grid сам решает, сколько колонок по 260px влезет. Если нужно ровно 1, 2 и 3 — медиазапросы.
:::
